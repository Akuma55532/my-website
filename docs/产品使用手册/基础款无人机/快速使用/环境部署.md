# 环境部署

本节用于完成 FanciSwarm® 基础款无人机的 UWB 定位环境部署。部署完成后，无人机才能正常使用轨迹飞行、集群飞行等依赖定位的功能。

本节只介绍基站安装、空间摆放和定位参数设置；ROS 工程将在后续的 [ROS 工程部署](./ROS工程部署.md) 中说明。

## 部署前准备

开始前，请准备以下设备和工具：

- 4 个 FanciSwarm® UWB 基站及其配套支架；
- 需要参与飞行的 FanciSwarm® 基础款无人机；
- 已安装 FanciSwarm App 的手机；
- 卷尺或激光测距仪；
- 用于标记坐标轴、原点和基站位置的胶带或标识物；
- 空旷、无人员穿行，并且能够满足安全距离要求的飞行区域。

:::info[本节完成标准]

完成本节后，应满足以下条件：4 个基站安装牢固且朝向正确；每个基站的 ID、实际位置和 App 中填写的坐标一致；每架无人机的标签 ID 唯一；参数写入后所有无人机均已重启。

:::

## 一、了解 UWB 基站

FanciSwarm® 高精度 UWB 定位系统基于超宽带无线电技术（Ultra Wideband，简称 UWB），用于计算无人机在空间中的绝对三维位置，即 X、Y、Z 坐标。

无人机自带 UWB 标签。系统通过基站和标签之间的高频无线电通信，测量无人机与各个基站之间的距离，再由定位算法计算无人机的位置。轨迹飞行、集群飞行和编队飞行等功能均依赖这套定位系统。

一套 FanciSwarm® 基站包含 4 个基站，基站颜色可能为黑色或灰色，以实际收到的设备为准。

![一套包含四个基站的 FanciSwarm UWB 定位设备俯视图](/产品使用手册/使用手册/基础款/uwb1.png)

## 二、安装并固定基站

请先根据收到的基站款式完成安装。新款和旧款基站的结构及安装角度不同，不要混用两种安装方式。

### 新款 UWB 基站

新款基站的 UWB 模组与基站主体采用分离式设计：

1. 将 UWB 模组连接到基站主体；
2. 使用配套支架上的伸缩夹夹紧基站；
3. 调整支架，使基站主体竖直向上；
4. 确保 UWB 模组朝向飞行区域。

![新款 UWB 基站的组成、安装方式和朝向](/产品使用手册/使用手册/基础款/uwb2.png)

### 旧款 UWB 基站

旧款基站应使用配套支架上的伸缩夹固定，并使基站向下倾斜约 10°，确保白色的 UWB 天线平面朝向飞行区域。

![旧款 UWB 基站的天线位置和安装朝向](/产品使用手册/使用手册/基础款/uwb3.png)

:::warning[确认基站款式]

新款基站保持主体竖直、UWB 模组朝向飞行区域；旧款基站向下倾斜约 10°、白色天线平面朝向飞行区域。应以对应款式的安装图为准。

:::

## 三、建立坐标系并摆放基站

### 1. 建立基站坐标系

按照下图建立基站坐标系：X 轴和 Y 轴位于地面平面，Z 轴垂直向上且向上为正方向。建议在地面上标出坐标原点、X 轴正方向和 Y 轴正方向，避免测量及录入坐标时混淆。

四个基站均标有 1～4 的 ID。摆放和录入参数时，必须保证基站实物 ID、摆放位置和 App 参数中的基站编号一一对应。

![四个 UWB 基站在三维坐标系中的摆放示意图](/产品使用手册/使用手册/基础款/uwb4.png)

### 2. 参考坐标

下面是一组便于理解摆放方式的参考坐标，单位均为厘米（cm）：

| 基站 ID | X（cm） | Y（cm） | Z（cm） |
| --- | ---: | ---: | ---: |
| 基站 1 | 80 | -80 | 160 |
| 基站 2 | 0 | 400 | 170 |
| 基站 3 | 400 | 400 | 170 |
| 基站 4 | 400 | 0 | 170 |

:::note[参考坐标不能直接代替现场测量]

实际坐标应根据实验场地重新测量。App 中填写的坐标必须与基站的实际位置一致，否则会直接影响定位精度。

:::

### 3. 摆放示例

下图展示了一个实际场地中的摆放示例。图中以地面标记点为坐标原点 `(0, 0, 0)`，红色箭头表示 X、Y、Z 轴正方向；每个基站旁标注了基站 ID 和对应的 `(X, Y, Z)` 坐标，坐标单位为厘米（cm）。

![FanciSwarm UWB 四基站实际场地摆放示例](/产品使用手册/使用手册/基础款/sample.png)

该图片用于说明坐标系、基站编号和坐标记录方式。实际部署时，应根据现场尺寸重新确定坐标原点并测量各基站坐标，不要直接照抄图中的数值。

### 4. 摆放要求

摆放时请逐项确认：

1. 按照基站 ID 1～4 依次放置，不得互换编号；
2. 基站 1 与其余三个基站在 X、Y、Z 三个坐标上都不相同；
3. 基站 2、基站 3 和基站 4 的 Z 坐标保持一致；
4. 四个基站的安装高度应高于无人机计划飞行的高度；
5. 无人机的计划飞行轨迹与任意基站之间的距离应大于 2 米；
6. 基站与墙壁、天花板及金属物体之间至少保留 15 厘米距离，减少反射干扰；
7. 所有基站都应固定牢靠，并按照对应款式的要求朝向坐标系内侧的飞行区域；
8. 摆放完成后，记录每个基站相对于坐标原点的 X、Y、Z 坐标，单位为厘米。

## 四、设置定位参数

基站摆放完成后，需要使用 FanciSwarm App 为 UWB 定位系统内的每一架无人机写入定位参数。App 的安装、连接和基础界面请参阅通用教程中的 [App 使用手册](../../../通用教程/App使用手册.md)。

![FanciSwarm App 中需要设置的 UWB 定位参数](/产品使用手册/使用手册/基础款/para_set.png)

### 1. 参数说明

| 参数 | 填写要求 |
| --- | --- |
| 坐标偏航角 | 使无人机机头朝向基站坐标系 X 轴正方向，并让机体与 X 轴平行；读取 App 主界面姿态球显示的偏航角，按整数填写。 |
| 标签 ID | 无人机编号，必须从 1 开始且每架无人机互不相同。标签 ID 与 ROS 工程通信节点一一对应，例如标签 ID 为 `1` 时，对应节点编号为 `001`，即 `fcu_bridge_001.cpp`。 |
| 标签总数 | 填写当前 UWB 定位系统中处于开机状态的无人机实际总数，按整数填写。每架无人机填写的总数应保持一致。 |
| 基站 1～4 位置 | 分别填写对应基站的 X、Y、Z 实测坐标，单位为厘米，按整数填写。基站 ID 与坐标不得错位。 |

:::danger[参数必须与现场一致]

标签 ID 重复、标签总数与实际开机数量不符，或基站编号和坐标对应错误，都会导致定位或集群通信异常。请在写入前逐项复核。

:::

### 2. 参数设置步骤

1. 打开全部需要参与本次飞行的无人机；
2. 使用 FanciSwarm App 连接其中一架无人机；
3. 进入定位参数设置页面；
4. 填写坐标偏航角、标签 ID、标签总数，以及基站 1～4 的 X、Y、Z 坐标；
5. 写入参数，并确认 App 提示设置成功；
6. 依次连接其余无人机，填写相同的基站坐标和标签总数，同时为每架无人机设置唯一的标签 ID；
7. 全部参数设置完成后，逐架重启无人机。

## 五、重启并检查

定位参数只有在无人机重启后才能按本次配置工作。设置完最后一项参数后，不要直接起飞，请先完成以下检查：

- 4 个基站的安装方向和实物 ID 正确；
- App 内的 4 组基站坐标与现场实测值一致；
- 所有无人机的标签 ID 从 1 开始且没有重复；
- 所有无人机填写的标签总数与实际开机数量一致；
- 所有无人机均已完成参数写入并重新启动；
- 无人机定位数据稳定后，再进入后续飞行操作。

如果调整了基站位置、改变了坐标系方向，或增减了参与飞行的无人机，应重新核对并写入相关参数，然后再次重启无人机。
