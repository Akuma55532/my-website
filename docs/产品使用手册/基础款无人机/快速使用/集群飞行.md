# 集群飞行

## 一、配置组网模块

配置组网模块需要借助路由器，共有以下两种方法。方法一更简单，建议优先使用。

### 方法一：使用 Mlink-esp 调试器配置

Mlink-esp 调试器为新增配件，可以简化组网配置步骤。FanciSwarm® 集群套件用户如果缺少该配件，可通过之前的购买渠道向幻思创新申请，申请通过后将免费寄送。

该方法需要先将 Mlink-esp Wi-Fi 模块与 Mlink-esp 调试器连接，再通过 USB 接口将调试器连接到电脑，共分为以下 6 步。

#### 1. 连接 Mlink-esp 调试器

从 FanciSwarm® 无人机上取下 Mlink-esp Wi-Fi 模块，按照下图所示连接 Mlink-esp 调试器。

:::danger[特别注意]

请勿接反，接反必烧！

:::

![Mlink-esp Wi-Fi 模块与 Mlink-esp 调试器的连接方式](/产品使用手册/使用手册/基础款/mlink-setting.png)

#### 2. 下载串口助手

点击下载 [串口助手 sscom5.13.1](https://fancinnov.com/download/sscom5.13.1%202.rar)。下载并解压后会得到 `sscom5.13.1.exe`，双击安装即可。

#### 3. 打开串口助手并连接 Mlink-esp 调试器

打开上一步下载的串口助手，将 Mlink-esp 调试器连接到电脑。

#### 4. 设置串口助手

如下图所示，先点击端口号处的下拉按键，再选中第一行“……USB-SERIAL CH340”，最后在输入框中输入下一步的 AT 指令。

![串口助手端口选择与 AT 指令输入位置](/产品使用手册/使用手册/基础款/mlink-setting2.png)

#### 5. 发送 AT 指令

在输入框中依次输入并发送以下 AT 指令。

1. 重启模块：

   ```text
   AT+RST\r\n
   ```

2. 恢复出厂设置：

   ```text
   AT+RESTORE\r\n
   ```

3. 设置为 Station 模式，默认模式为 AP：

   ```text
   AT+CWMODE_DEF=1\r\n
   ```

4. 设置要连接的路由器名称和密码：

   **特别注意：Wi-Fi 名称不能使用中文。**

   ```text
   AT+CWJAP_DEF="WiFi名称","WiFi密码"\r\n
   ```

   例如：

   ```text
   AT+CWJAP_DEF="Fancinnov","Mcontroller"\r\n
   ```

   如果串口助手接收界面显示 `WIFI CONNECTED`，说明组网模块已成功连接路由器；显示 `WIFI GOT IP`，说明模块已分配到 IP。否则请重新检查并尝试，直到连接成功。

5. 查询 IP 地址：

   ```text
   AT+CIFSR\r\n
   ```

   指令发送成功后，串口助手接收界面会显示路由器分配给该组网模块的 IP 地址。

6. 设置固定 IP 地址：

   ```text
   AT+CIPSTA_DEF="ip","网关","子网掩码"\r\n
   ```

   例如，上一步查询到的 IP 地址为 `192.168.0.2`，则发送：

   ```text
   AT+CIPSTA_DEF="192.168.0.100","192.168.0.254","255.255.255.0"\r\n
   ```

   指令中的符号均为英文符号。`192.168.0.100` 中的 `100` 可以替换为 `1～254` 中的其他值，但不得与连接该路由器的其他设备 IP 重复，建议使用 `100` 以上的值。

7. 再次查询 IP 地址：

   ```text
   AT+CIFSR\r\n
   ```

   如果串口助手返回的 IP 地址与上一步设置的一致，说明 IP 设置成功。请牢记该 IP 地址。

配合 App 使用时，先打开 App，让手机连接目标路由器 Wi-Fi，再点击首页右上角的数传连接按钮，在输入框中填写配置好的组网模块 IP。

#### 6. 配置完成

至此，Mlink-esp 组网模块配置完成。

### 方法二：修改固件

该方法需要确保 Mlink-esp Wi-Fi 模块与 FanciSwarm® 无人机接插稳定，共分为以下 9 步。

#### 1. 下载固件工程和依赖包

[点击下载固件工程和依赖包](https://fancinnov.com/download-FanciSwarm-after1120)。

#### 2. 配置为透传模式

请参照工程开发指南，在 `Clibrary/include/config.h` 中，将默认的非透传模式：

```cpp
#define COMM_0 MAV_COMM
```

改为透传模式：

```cpp
#define COMM_0 CONFIG_COMM
```

完成配置后，请重新编译。

特别说明：

1. 透传模式下，可直接通过 USB 线连接 FanciSwarm®，向其中的 Mlink-esp 组网模块发送指令，无需使用 USB 转 TTL 模块；
2. 非透传模式下，FanciSwarm® 处于正常工作状态；
3. Mlink-esp 组网模块配置完成后，必须按第 8 步将其重新配置为非透传模式。

#### 3. 重新烧录固件

请参照程序烧录指南，将上一步编译后重新生成的 `.hex` 文件烧录到 FanciSwarm® 中。

#### 4. 下载串口助手

点击下载 [串口助手 sscom5.13.1](https://fancinnov.com/download/sscom5.13.1%202.rar)。下载并解压后会得到 `sscom5.13.1.exe`，双击安装即可。

#### 5. 打开串口助手并连接 FanciSwarm®

打开串口助手，再通过 USB 线将 FanciSwarm® 无人机连接到电脑。


   例如：


   如果串口助手接收界面显示 `WIFI CONNECTED`，说明组网模块已成功连接路由器；显示 `WIFI GOT IP`，说明模块已分配到 IP。否则请重新检查并尝试，直到连接成功。


   指令发送成功后，串口助手接收界面会显示路由器分配给该组网模块的 IP 地址。

7. 再次查询 IP 地址：


#### 8. 重新配置为非透传模式并烧录固件

Mlink-esp 组网模块配置完成后，必须将 FanciSwarm® 恢复为非透传模式。请参照工程开发指南，在 `Clibrary/include/config.h` 中，将：


## 三、编译 ROS 工程

### 1. Clone 依赖库

在工作空间的 `src` 文件夹中打开终端，输入以下命令并按回车键，将依赖库 `quadrotor_msgs` 克隆到 `src` 文件夹中：

```bash
git clone https://gitee.com/fancinnov/quadrotor_msgs.git
```

### 2. 运行 catkin_make

在工作空间 `ros-ws` 下运行 `catkin_make` 编译工程，注意不要在 `src` 文件夹中运行。

第一步，打开终端并输入：

```bash
cd ros-ws
```

第二步，接着输入：

```bash
catkin_make
```

### 3. 确认编译成功

运行 `catkin_make` 后，编译进度达到 `100%`，说明编译成功。

![catkin_make 编译达到 100%](/产品使用手册/使用手册/基础款/ros-build.png)

编译成功后，工作空间 `ros-ws` 下会生成 `build` 和 `devel` 文件夹。

![编译后生成 build 和 devel 文件夹](/产品使用手册/使用手册/基础款/ros-build2.png)

其中，`build` 文件夹用于存放编译生成的二进制文件；`devel` 文件夹用于存放开发环境中的可执行文件和库。

如果编译失败，请根据终端中的报错日志修改代码。

## 四、摆放基站

请参照 [环境部署](./环境部署.md) 中的基站摆放说明进行操作。

## 五、设置定位参数

请参照 [环境部署](./环境部署.md) 中的定位参数设置说明，依次为每一架 FanciSwarm® 无人机设置参数。

3 台 FanciSwarm® 无人机的标签 ID 需要分别设置为 `1`、`2` 和 `3`。请在对应的无人机上贴出标识用于区分，切勿混淆。

- 标签 1（1 号 FanciSwarm® 无人机）对应通信节点 001，即 ROS 工程中的 `fcu_bridge_001.cpp`；
- 标签 2（2 号 FanciSwarm® 无人机）对应通信节点 002，即 ROS 工程中的 `fcu_bridge_002.cpp`；
- 标签 3（3 号 FanciSwarm® 无人机）对应通信节点 003，即 ROS 工程中的 `fcu_bridge_003.cpp`。

## 六、放置 FanciSwarm® 无人机

### 1. 确定轨迹起点坐标

每台 FanciSwarm® 无人机都需要放置在各自轨迹的起点处。起点坐标请根据“集群轨迹设计与开发”一节确认。

默认轨迹的起点坐标为：

- 1 号 FanciSwarm® 无人机：`(3, 2)`；
- 2 号 FanciSwarm® 无人机：`(2.5, 2.866)`；
- 3 号 FanciSwarm® 无人机：`(1.5, 2.866)`。

上述默认轨迹起点坐标均为基站坐标系下的坐标。

### 2. 放置无人机

依次将每台 FanciSwarm® 无人机放置在各自轨迹的起点处，机尾面朝用户。

## 七、重启无人机并开启基站

1. 按复位键重启每台 FanciSwarm® 无人机；
2. 开启 4 个基站，开启顺序不限；
3. 观察每一台 FanciSwarm® 无人机及基站的 LED6 状态，即 UWB 指示灯状态；
4. LED6 快速闪烁时，说明 FanciSwarm® 无人机的 UWB 定位正常，高精度 UWB 定位系统工作正常，可以继续下一步。否则请重启每一台无人机和基站，再次尝试。

## 八、运行 ROS 工程

说明：

1. FanciSwarm App 与 ROS 不能同时连接无人机，同一时刻只能使用其中一种方式连接；
2. 遥控器与 ROS 可以同时连接无人机。使用 ROS 控制时，需要将遥控器控制模式切换至自主模式档位；直接使用遥控器控制时，需要切换至位置模式档位；
3. 遥控器油门始终有效。油门低于 `0.4` 时无人机下降，高于 `0.6` 时无人机上升，处于 `0.4～0.6` 时无人机保持悬停。如果由 ROS 控制飞行高度，需要将遥控器油门持续保持在 `0.4～0.6` 范围内。

![遥控器 CH5 和 CH7 三段开关位置](/产品使用手册/使用手册/基础款/rc_ch7_ch5.png)

### 1. 程序注册

在工作空间 `ros-ws` 下运行 `source devel/setup.bash`。

第一步，重新打开终端并输入：

```bash
cd ros-ws
```

第二步，接着输入：

```bash
source devel/setup.bash
```

### 2. 配置 USB 通信权限（不使用 USB 通信时忽略）

如果使用 USB 通信，需要在终端输入：

```bash
sudo chmod 777 /dev/ttyACM0
```

### 3. 运行工程

运行 ROS 工程前请注意：

- 单机飞行时，电脑需要连接无人机的 Mlink Wi-Fi；
- 多机飞行时，电脑和无人机需要接入同一局域网。

请再次确认每一台 FanciSwarm® 无人机均已重启，每一个基站均已开启并正常工作。

在 `ros-ws` 文件夹下输入：

```bash
roslaunch fcu_core fcu_core.launch
```

### 4. 确认运行成功

终端界面出现连接成功提示，并打印每一台 FanciSwarm® 无人机的电压和电流信息时，说明 ROS 工程运行成功，可以继续下一步。如果运行失败，终端会显示连接错误，请检查上述操作后再次尝试。

![3 个通信节点连接成功并输出无人机状态](/产品使用手册/使用手册/基础款/swarm-ros-run.png)

同时，系统会自动打开 RViz 界面。下图中的坐标点仅供参考，以实际运行效果为准。

![RViz 中 3 架无人机的位置点](/产品使用手册/使用手册/基础款/swarm-rviz.png)

1. RViz 是一个三维可视化平台，用于显示 FanciSwarm® 无人机的位置和飞行轨迹；
2. 右侧 3D 视图区中的坐标轴代表世界坐标系，红轴为 X 轴、绿轴为 Y 轴、蓝轴为 Z 轴；
3. 红点代表 1 号无人机（通信节点 001）在世界坐标系中的位置，绿点代表 2 号无人机（通信节点 002）的位置，蓝点代表 3 号无人机（通信节点 003）的位置。

## 九、检查轨迹

依次拿起 1、2、3 号 FanciSwarm® 无人机，各自走一圈。随后通过 RViz 仔细核查每一架无人机的轨迹。确认所有无人机的轨迹都显示正确后，再继续后续操作。

## 十、飞行前检查

:::danger[特别注意]

FanciSwarm® 无人机起飞前，请仔细检查以下每一项。

:::

1. 确保 FanciSwarm® 无人机放置在水平面，用户面朝机尾；
2. 确保 FanciSwarm® 无人机前、后、左、右 2 m 范围内空旷无墙壁、无杂物，严禁在小于该范围的空间内起飞；
3. 室内起飞前，确认地面具有清晰、可识别的纹理。避免地面为纯色、过暗、过亮或存在强反光区域，以免影响光流定位和飞行稳定性；
4. 室外起飞且搭载高精度 GNSS 模组时，不需要关注地面纹理，只需关注 FanciSwarm® App 主界面的 GNSS 定位状态，具体说明参照“FanciSwarm® 飞行”章节；
5. 确保电池连接线不会被螺旋桨刮到；
6. 确保每个螺旋桨按照“用户手册 → FanciSwarm® 无人机 → 螺旋桨”一节的说明正确且牢固地安装；
7. 确保每个螺旋桨无破损、老化和变形；
8. 确保 FanciSwarm® 无人机、手机或遥控器电量充足；
9. 确保 FanciSwarm® 固件版本和 FanciSwarm App 版本与幻思创新官网一致。

### 室内地垫说明

推荐使用尺寸为 `30 × 30 × 1 cm` 的不同颜色地垫。集群套件用户和智能套件用户附赠；基础款套件用户和树莓派套件用户如需自行采购，可以使用以下链接：

[淘宝链接（点击购买）](https://e.tb.cn/h.hMiitwrtPywzujw?tk=RVcs456ddxg+CZ225)

请选择尺寸为 `30 × 30 × 1 cm` 的地垫，并购买白色、蓝色、灰色等多种颜色，切勿只选择单一颜色，以保证光流定位的纹理识别效果和稳定性。

这种地垫可以使地面纹理更加清晰，帮助光流模块定位；其材质也比瓷砖或水泥地更柔软，可以保护无人机。

为确保无人机能够准确识别地面纹理并稳定定位，集群套件用户和智能套件用户必须使用附赠的地垫。收到后，请将每片地板按边长 30 cm 拆分为 4 块，再进行铺设：

1. 每块地板尺寸为 `30 × 30 × 1 cm`，表面由白色、蓝色和灰色 3 种颜色构成；
2. 将每块地垫按边长 30 cm 拆分为 4 块；
3. 按照 3 种不同颜色交替排列，以增强地面图案的辨识度。

![不同颜色地垫交替铺设示例](/产品使用手册/使用手册/基础款/block.png)

:::danger[禁止在以下地面起飞]

纯色大理石瓷砖、木地板，以及纯色或具有重复纹理方格图案的地板会影响无人机光流定位，因此严禁起飞。为确保飞行安全，飞行前请联系幻思创新工程师确认环境是否适宜。

:::

## 十一、飞行测试（基站开启）

基站开启后，使用遥控器依次对 1、2、3 号 FanciSwarm® 无人机进行飞行测试。确认每一架无人机的飞行状态都稳定后，再继续后续步骤。

具体操作请参照“快速入门指南 → FanciSwarm® 飞行 → 使用遥控器飞行”。

:::danger[特别注意]

遥控器上的 CH7 三段开关需要设置在中间位置，即位置模式。遇到飞行异常时，可将 CH7 切换至最上方、靠近 CH8 的姿态模式档位，以防无人机失控。

:::

## 十二、清除 RViz 界面轨迹

开始运行新轨迹前，必须清除 RViz 中已有的轨迹。先退出当前 ROS 工程，再重新运行工程。

### 1. 退出 ROS 工程

1. Windows 电脑按 `Ctrl + C`，Mac 电脑按 `Command + C`；
2. 接着按回车键，退出 ROS 工程。

![退出 ROS 工程](/产品使用手册/使用手册/基础款/ros_exit.png)

### 2. 重新运行 ROS 工程

按照本页“运行 ROS 工程”一节中的步骤重新运行工程。

## 十三、测试单机运行轨迹

开始集群飞行前，必须通过 ROS 对每一架无人机进行单独试飞，确认其运行状态正常。只有所有参与集群飞行的无人机都通过测试后，才能执行多机集群飞行。

测试任意一架无人机前：

1. 确保其他两架无人机处于关闭状态；
2. 按照“放置 FanciSwarm® 无人机”一节，将正在测试的无人机放置在对应轨迹的起点处；
3. 按照后面的“开始运行轨迹”“停止运行轨迹”和“退出 ROS 工程”依次测试每一架无人机。

确认每一架无人机均通过飞行轨迹测试，并且轨迹运行正常后，才能进行多机集群飞行。

## 十四、开始运行轨迹

开始前，先开启 1、2、3 号 FanciSwarm® 无人机，并按照“放置 FanciSwarm® 无人机”一节，将它们放置在各自轨迹的起点处；然后运行 ROS 工程，再按照以下步骤运行轨迹。

工程运行后，在 Ubuntu 终端中输入“指令字符 + 回车”，即可下发对应指令。所有指令字符都在 `fcu_command.cpp` 中定义，用户可以仿照源码进行自定义。

### 1. 解锁 FanciSwarm® 无人机

解锁前请注意：

1. 确认起落架结构稳固、安装牢靠，无松动、无损坏；
2. 未搭载高精度 GNSS 模组的机型：无人机启动提示音结束后，将无人机垂直拿起一次，抬到距离地面超过 1 m 后放下。激光测距正常时才能解锁；否则无人机会发出连续报警音，同时固件强制锁定，不允许起飞；
3. 搭载高精度 GNSS 模组的机型：首次开机时，请等待 GNSS 模组蓝色 LED 长亮，确认当前环境的 GNSS 信号良好后再解锁。蓝色 LED 未保持长亮时，尝试解锁会触发连续报警音，同时固件强制锁定，不允许起飞。

完成上述检查后，在终端输入 `a` 并按回车键，界面会打印“解锁”。

```text
a
```

![在 ROS 终端输入 a 解锁无人机](/产品使用手册/使用手册/基础款/a_armed.png)

此时，3 台 FanciSwarm® 无人机的电调指示灯同时点亮，Mcontroller 右侧绿色 LED 同时点亮，并伴随启动声音。无人机完成解锁。

### 2. 一键起飞

在终端输入 `t` 并按回车键，界面会打印“起飞”。

```text
t
```

![在 ROS 终端输入 t 一键起飞](/产品使用手册/使用手册/基础款/t_takeoff.png)

此时，3 台 FanciSwarm® 无人机同时起飞到 FanciSwarm App 中设置的起飞高度并悬停。

如果需要降落，可以在终端输入 `l`（小写 L）并按回车键，无人机将开始降落并着陆。

### 3. 开始运行轨迹

在终端输入 `r` 并按回车键，界面会打印“运行”。

```text
r
```

![在 ROS 终端输入 r 开始运行轨迹](/产品使用手册/使用手册/基础款/r_run.png)

此时，3 台 FanciSwarm® 无人机同时开始飞圆轨迹。

## 十五、停止运行轨迹

### 1. 停止轨迹

在终端输入 `s` 并按回车键，界面会打印“停止”。

```text
s
```

![在 ROS 终端输入 s 停止运行轨迹](/产品使用手册/使用手册/基础款/s_stop.png)

此时，3 台 FanciSwarm® 无人机同时停止飞圆轨迹，并保持悬停状态。

### 2. 一键降落

在终端输入 `l`（小写 L）并按回车键，界面会打印“降落”。

```text
l
```

![在 ROS 终端输入 l 一键降落](/产品使用手册/使用手册/基础款/l-land.png)

此时，3 台 FanciSwarm® 无人机同时开始降落并着陆。

### 3. 锁定 FanciSwarm® 无人机

等待无人机着陆后，在终端输入 `d` 并按回车键，界面会打印“锁定”。

```text
d
```

![在 ROS 终端输入 d 锁定无人机](/产品使用手册/使用手册/基础款/d_disarmed.png)

此时，3 台 FanciSwarm® 无人机的电调指示灯同时熄灭，Mcontroller 右侧绿色 LED 熄灭、红色 LED 点亮。无人机完成锁定。

## 十六、退出 ROS 工程

1. Windows 电脑按 `Ctrl + C`，Mac 电脑按 `Command + C`；
2. 接着按回车键，退出 ROS 工程。

![退出 ROS 工程](/产品使用手册/使用手册/基础款/ros_exit%20(1).png)

## 十七、关闭无人机和基站

FanciSwarm® 无人机锁定后，如果不继续飞行，请及时关闭每台无人机和基站，并拔掉电池，避免电量损耗。

至此，整个集群飞行过程完成。
