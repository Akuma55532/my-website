# 环境部署

现在我们开始进行无人机的环境部署

## 树莓派系统烧录

将64G的SD卡放入读卡器

首先下载[树莓派官方烧录镜像工具](https://downloads.raspberrypi.com/imager/imager_latest.exe)

安装之后打开烧录镜像工具

首先进行格式化操作：

1. 设备-->`Raspberry Pi 5`
2. 操作系统-->`格式化`
3. 储存设备-->`SD卡`
4. 点击写入

下载[幻思提供的镜像](https://akuma-mywebsite.oss-cn-chengdu.aliyuncs.com/images/2025-05-13-raspios-bookworm-arm64.img.xz)

格式化过SD卡之后我们可以进行镜像烧录：

1. 设备-->`Raspberry Pi 5`
2. 操作系统-->`使用自定义镜像`-->下载[幻思提供的镜像](https://akuma-mywebsite.oss-cn-chengdu.aliyuncs.com/images/2025-05-13-raspios-bookworm-arm64.img.xz)并选择
3. 储存设备-->`SD卡`
4. 点击写入

进入系统初始化界面之后，一路继续，建议用户名使用`pi`，密码使用`123456`，和我们案例一致，避免忘记密码的情况出现。最后忽略更新软件更新步骤，直接重启。

重启之后开启SSH和串口硬件

![](../../../static/产品使用手册/使用手册/树莓派5/ssh-config1.png)


![](../../../static/产品使用手册/使用手册/树莓派5/ssh-config2.png)

:::note

`Serial Console`也需要disable，会影响串口的正常工作。

:::

## 安装必要的python环境

下载[树莓派5工程包](https://akuma-mywebsite.oss-cn-chengdu.aliyuncs.com/packages/raspberry%20pi%205%20packages.zip)并解压

将工程包放置树莓派根目录(/home/pi)并执行环境部署脚本

~~~shell
cd ./yolo
sudo chmod +x ./autodeploy.sh
./autodeploy.sh
~~~

最后会要求你重启系统，建议直接重启，不然无法使用摄像头。

进行环境测试

~~~shell
cd ~/yolo
source ./.venv/bin/activate
yolo export model=yolo26n.pt format=ncnn # turn pt into ncnn(faster)
python test.py # run test script
~~~

正常的话就能够看到无人机摄像头里的内容了

## 开机自启动

创建桌面自动启动项

~~~
mkdir -p ~/.config/autostart
nano ~/.config/autostart/yolo-systemd.desktop
~~~

写入：

~~~
[Desktop Entry]
Type=Application
Name=MyPythonScript
Exec=lxterminal --command "cd /home/pi/yolo && /bin/bash -c 'source /home/pi/yolo/.venv/bin/activate && python /home/pi/yolo/detect.py'"
~~~

这样流程就是：

~~~
pi 登录桌面
→ 导入当前桌面 DISPLAY/Wayland 环境
→ 启动 user systemd 服务
→ OpenCV 的 cv2.imshow() 窗口显示在桌面
~~~

然后重启树莓派测试：

~~~
sudo reboot
~~~

:::note

默认自启动程序运行 python detect.py,需要启动什么文件就将文件名更改为detect.py即可。

:::
