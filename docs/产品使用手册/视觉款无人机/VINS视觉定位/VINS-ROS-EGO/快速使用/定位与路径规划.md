# 定位与路径规划

本页介绍 VINS-ROS-EGO 的定位方式选择、VINS 标定、EGO 参数配置，以及通过 ROS 下发目标点的操作。软件和工程安装见 [环境部署](./环境部署.md)。

## 一、选择定位方式

是否启用 VINS 定位，请先联系幻思创新工程师评估实际使用环境。

VINS 定位要求相机视野内具有充足光照，以及丰富、稳定的纹理特征。如果现场光照不足、纹理较少或特征不明显，材料建议不启用 VINS，改用无人机下视光流定位；使用光流定位时，飞行区域地面需要具有可辨识的纹理特征。

根据实际情况选择下面的方案，不需要同时执行两种配置。

## 二、不启用 VINS 定位

### 1. 修改自启动脚本

打开 `auto_ap.sh`，将下图框出的 VINS 自启动部分注释掉：

![关闭 VINS 自启动](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/vins-disable-autostart.png)

### 2. 烧录光流定位固件

从 [FanciSwarm 固件及依赖包下载页](https://www.fancinnov.com/download-FanciSwarm-after1120) 获取固件，烧录官网下载的默认固件，使用光流定位模式。

烧录工具与相关说明见 [通用教程：Mcontroller-V7 使用手册](../../../../../通用教程/Mcontroller-V7使用手册.md)。

### 3. 使用 App 配置波特率

在 App 的参数列表中，将 **串口 1 波特率设置为 `460800`**。

App 的连接和界面说明见 [通用教程：App 使用手册](../../../../../通用教程/App使用手册.md)。

## 三、启用 VINS 定位

### 1. 配置飞控固件参数

#### 固件兼容要求

材料要求无人机固件不低于 `V7.1.8-2025032001`。低于该要求时，先从 [固件下载页](https://www.fancinnov.com/download-FanciSwarm-after1120) 更新固件。

#### 修改配置

在固件工程的 [Clibrary/include/config.h](https://github.com/fancinnov/Mcontroller-v7-FanciSwarm/blob/main/Clibrary/include/config.h) 中，按照下图配置参数：

![VINS 定位所需的飞控参数](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/vins-flight-controller-config.png)

图中标出的配置包括：

```cpp
#define COMM_1 MAV_COMM
#define USE_MAG 0
#define USE_ODOMETRY 1
#define USE_VINS 1
```

`USE_VINS` 为 `1` 时启用 VINS，为 `0` 时不使用 VINS。本节配置为 `1`。

:::caution[串口波特率通过 App 设置]

图中的 `COMM_1_BANDRATE` 不能代替 App 参数设置。对于材料标明的固件 `≥ V7.1.8-2025042201`、App `≥ V1.3.4`，需要在 App 参数列表中将串口 1 波特率设置为 `460800`，仅修改代码中的波特率无效。

:::

参数配置完成后，重新编译固件。

### 2. 烧录固件并检查

将上一步编译生成的固件烧录到无人机。相关工具见 [Mcontroller-V7 使用手册](../../../../../通用教程/Mcontroller-V7使用手册.md)。

烧录后重启机载电脑。已配置自启动时，`fcu_core`、VINS 和 EGO 会自动运行。静态检查时，在 VINS 的 RViz 界面看到特征点和轨迹，说明材料中的固件参数配置已生效。

飞行时仍需遵守 [环境部署中的 RViz 使用说明](./环境部署.md#十全部工程自动运行)：机载 VINS RViz 会影响实时性，只用于静态测试，飞行时不要运行。

### 3. PID 调参

按照材料中的配置，通过 App 参数列表将 Roll 速率 P 和 Pitch 速率 P 均调整为 `0.09`：

![Roll 与 Pitch 速率 P 参数](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/vins-roll-pitch-pid.png)

### 4. VINS 参数配置与标定

#### 相机内参

`VINS-Fusion-gpu/config/realsense_d435i` 目录中包含：

```text
left.yaml
right.yaml
realsense_stereo_imu_config.yaml
```

在 `left.yaml` 和 `right.yaml` 中配置相机内参。原文写作 `left.yawl`，配图及相机配置中的实际名称为 `left.yaml`。

通过相机话题查看内参：

```bash
rostopic echo /camera/infra1/camera_info
rostopic echo /camera/infra2/camera_info
```

查看输出中的 `K` 矩阵，读取 `fx、cx、fy、cy`。对应矩阵位置如下，避免将右下角的 `1` 当作内参：

```text
fx   0  cx
 0  fy  cy
 0   0   1
```

材料中使用 `fx = fy`，并说明两个摄像头的参数通常相同；填写时以各自话题读到的内参为准。

![相机内参配置示例](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/vins-camera-intrinsics.png)

#### 双目与 IMU 配置

继续配置 `realsense_stereo_imu_config.yaml`，下图所示部分的参数均需核对：

![双目相机与 IMU 参数](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/vins-stereo-imu-config.png)

`output_path` 按实际输出文件夹路径填写，不直接照抄截图中的用户目录。

#### 相机外参标定

![相机外参矩阵](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/vins-camera-extrinsics.png)

1. 在 `realsense_stereo_imu_config.yaml` 中配置存储路径，材料中对应第 82 行。例如，在用户主目录建立 `vins_output` 文件夹。
2. 以提供的初始参数为基础，根据相机实际安装位置调整矩阵初值。
3. 通过 `auto_ap.sh` 启动工程，`fcu_core` 终端会输出 VINS 轨迹坐标和偏航角。
4. 拿起无人机，在光照和纹理良好的环境中走一圈。过程中，相机镜头应朝向光照、纹理良好的开阔区域。
5. 返回后如果 VINS 没有发散，用文本编辑器打开输出目录中的 `extrinsic_parameter.csv`，将其中的参数矩阵复制到 `realsense_stereo_imu_config.yaml`。
6. 重复上述过程，直到走一圈前后的 VINS 轨迹没有明显偏差。

#### GPU 与输出路径

其余参数保留提供工程中的配置。`use_gpu` 和 `use_gpu_acc_flow` 均设为 `1`，以启用材料中的 GPU 加速配置；`pose_graph_save_path` 按实际输出目录填写。

![GPU 加速与输出路径配置](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/vins-gpu-output-config.png)

#### 检查定位结果

完成调参后，用无人机电池供电，启动无人机并连接显示器，等待机载工程运行。拿起飞机在房间中远距离走几圈，再连接显示屏，核对 `fcu_core` 终端输出的 VINS 原始坐标与 RViz 中的轨迹坐标是否一致。

如果不一致，需要重新检查配置，也可以联系幻思创新工程师协助。

:::caution[初始化检查]

VINS 刚启动时，缓慢晃动无人机使其完成初始化，观察 `fcu_core` 输出的 VINS 坐标是否漂移；如果出现漂移，重新启动。

:::

### 5. 飞行测试：验证定位源

使用遥控器前，先完成下文的“飞行前检查”。

#### 有专业飞手：姿态模式起飞

将遥控器 CH7 三段开关拨到上档位，使用姿态模式起飞，再在空中切到中间档位（定点），检查定位是否漂移。测试中可以切回姿态模式接管。

这里对应原材料引用的“特别说明 2”中的①和②，当前阶段不执行③自主飞行。

**姿态模式对操作能力要求较高。飞行经验不足、不熟悉姿态模式的用户，严禁使用该模式。**

![遥控器定位源测试说明](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/rc-position-test-guide.png)

#### 无专业飞手：定点模式起飞

将 CH7 拨到中间档位，使用定点模式起飞。有相应飞行经验的用户，在出现定位异常时可以将 CH7 切到上档位，以姿态模式接管。

## 五、飞行前检查

原材料要求飞行前阅读官网的“FanciSwarm 飞行前检查”。与本方案相关的检查项整理如下：

- 无人机放在水平面上，操作者面朝机尾；前、后、左、右至少 `2 m` 范围内保持空旷。
- 确认环境光照良好、无风且无杂物。使用光流定位时保证地面纹理清晰，避免过暗、过亮和强反光；使用 VINS 时保证相机视野内光照和纹理满足定位要求。
- 确认起落架稳固、螺旋桨安装正确且牢固，无破损、老化和变形；电池连接线不会碰到螺旋桨。
- 确认无人机和控制设备电量充足，并满足固件、App 的兼容要求。

这些检查对应材料引用的 [视觉智能套件飞行前检查](https://www.fancinnov.com/support-FanciSwarm-JetsonOrin)。

## 六、启用 EGO 并下发目标点

原材料将这一流程分为以下 17 步。下发目标点使用个人电脑（远程电脑），不是无人机的机载电脑。

### 1. 确认操作流程

先检查定位和飞行状态，再配置远程通信、目标点和 ROS 工程，最后进行起降与目标点飞行测试。

### 2. 飞行测试

建议使用遥控器控制飞行，并通过 FanciSwarm Pro App 查看实时状态。先完成飞行前检查，确认无人机飞行稳定后再继续。

进入后续 ROS 连接阶段时，App 需断开：**App 与 ROS 不能同时连接无人机。**

### 3. 启用 VINS 定位

采用 VINS 方案且尚未启用时，先完成本页“启用 VINS 定位”中的固件参数、烧录、PID、VINS 调参，以及“EGO 参数配置”。已完成时可跳过重复配置。

再次确认飞行状态稳定后继续。

### 4. 配置组网模块

**单机：**无需额外组网配置，个人电脑连接无人机 Wi-Fi，使用默认 IP `192.168.4.1`。

**多机：**先给每架无人机的组网模块配置路由器信息和各自的固定 IP，配置方法见本页“组网配置补充”。记录各机 IP，后续配置通信节点时一一对应。

### 5. 配置个人电脑环境

本步在远程电脑上操作，不在机载电脑上操作。已配置完成可以跳过。使用 Ubuntu 20.04 和 ROS Noetic，ROS 安装见 [通用教程：安装 ROS](../../../../../通用教程/ROS/安装ROS.md)；需要虚拟机时见 [通用教程：VMware 虚拟机](../../../../../通用教程/VMware虚拟机.md)。

### 6. 导入 ROS 工程

在远程电脑的用户主目录下创建工作空间并获取工程：

```bash
mkdir -p ~/ros-ws/src
cd ~/ros-ws/src
git clone https://gitee.com/fancinnov/fcu_core.git
git clone https://gitee.com/fancinnov/quadrotor_msgs.git
sudo apt-get install ros-noetic-serial
sudo apt-get install libeigen3-dev
```

此处的 `ros-ws` 是远程电脑工作空间，和机载电脑上的 `ros_ws` 分开配置。

### 7. 配置通信节点参数

#### 单机

打开远程电脑工程中的 [fcu_bridge_001.cpp](https://github.com/fancinnov/fcu_core/blob/main/src/fcu_bridge_001.cpp)，按下图配置顶部参数：

![远程电脑通信节点参数](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/fcu-bridge-remote-parameters.png)

使用单机默认网络时，`DRONE_IP` 填写 `192.168.4.1`，不要照抄截图中的示例 IP。

#### 多机

以三机协同为例，需要分别配置：

| 无人机 | 通信节点 | 配置文件 |
| --- | --- | --- |
| 1 号 | 001 | `fcu_bridge_001.cpp` |
| 2 号 | 002 | `fcu_bridge_002.cpp` |
| 3 号 | 003 | `fcu_bridge_003.cpp` |

各节点参考单机方式配置，但 `DRONE_IP` 分别填写第 4 步为对应无人机设置的 IP。三个节点对应三个不同的无人机 IP，不要混用。

### 8. 设置目标点

目标点定义在 [fcu_mission.cpp](https://github.com/fancinnov/fcu_core/blob/main/src/fcu_mission.cpp) 中。

#### 坐标约定

- 原点：机载电脑 SLAM 启动时的位置。
- X 轴：SLAM 启动时的机头朝向。
- Y 轴：X 轴右侧 `90°` 方向。
- Z 轴：坐标系中垂直向下；目标点接口为与高度一致，将目标点 Z 值设置为高度。

#### 单机目标点

在 `void execute_mission_001(void)` 中设置目标点，单位为米。材料展示了 4 个示例目标点，可根据实际需求修改，不要求固定使用示例坐标。

![目标点配置示例上半部分](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/ego-waypoints-example-1.png)

![目标点配置示例下半部分](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/ego-waypoints-example-2.png)

#### 多机目标点

以三机协同为例，各节点对应函数如下：

| 通信节点 | 无人机 | 目标点函数 |
| --- | --- | --- |
| 001 | 1 号 | `void execute_mission_001(void)` |
| 002 | 2 号 | `void execute_mission_002(void)` |
| 003 | 3 号 | `void execute_mission_003(void)` |

参考 `execute_mission_001` 的结构和目标点设置方式，为另外两个函数配置各自目标点。

### 9. 编译 ROS 工程

在远程电脑的工作空间根目录执行，不在 `src` 中编译：

```bash
cd ~/ros-ws
catkin_make
```

确认编译完成且没有报错后继续。

### 10. 开启无人机

启动无人机，放在水平面上，确保机尾朝向操作者。

### 11. 运行 ROS 工程

单机时，远程电脑连接无人机的 Mlink Wi-Fi；多机时，电脑与无人机连接同一路由器网络。

在远程电脑上运行：

```bash
cd ~/ros-ws
source devel/setup.bash
roslaunch fcu_core fcu_core.launch
```

如果改用 USB 通信，先为对应串口设置权限；材料所引用的 ROS 操作中使用：

```bash
sudo chmod 777 /dev/ttyACM0
```

终端显示连接成功，并输出无人机电压、电流等状态后，再继续检查轨迹。

### 12. 检查轨迹

拿起无人机走一圈，通过远程电脑的 RViz 界面检查轨迹。确认轨迹显示正确后，再进行后续操作。

### 13. 清除 RViz 轨迹

退出远程 ROS 工程，再按第 11 步重新运行，清除已有轨迹。材料引用的退出方式为：Windows 按 `Ctrl + C`，Mac 按 `Command + C`，再按回车。

### 14. 飞行测试：键盘起降

分别测试每架无人机的一键起飞、一键降落功能。

#### 解锁前检查

1. 等待无人机启动提示音结束，垂直拿起一次，到离地超过 `1 m` 后放下。激光测距正常才允许解锁；否则无人机会发出“滴滴滴……”报警音，固件强制锁定，不允许起飞。
2. App 与 ROS 同一时刻只能连接一个，使用 ROS 前断开 App。
3. 遥控器和 ROS 可以同时连接，建议保持遥控器连接，以便异常时接管。由 ROS 控制时将 CH7 切到自主模式（下档位）；直接用遥控器控制时切到定点模式（中间档位）。
4. 遥控器油门始终有效：低于 `0.4` 时下降，高于 `0.6` 时上升，处于 `0.4～0.6` 时悬停。由 ROS 控制高度时，将油门持续保持在 `0.4～0.6`，避免干扰高度控制。

![遥控器控制模式与高度模式](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/rc-control-mode-switches.png)

#### 第一步：解锁

确认 ROS 工程已运行，遥控器处于自主模式。在终端输入 `a`，再按回车，不要求输入后立即回车。终端显示“解锁”，无人机伴随启动声音完成解锁。

![ROS 解锁指令结果](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/ros-command-arm.png)

#### 第二步：一键起飞

输入 `t`，再按回车。终端显示“起飞”，无人机上升到设定高度后悬停。起飞高度可通过 App 设置，但使用 ROS 连接时仍需断开 App。

![ROS 起飞指令结果](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/ros-command-takeoff.png)

#### 第三步：一键降落

输入小写字母 `l`，再按回车。终端显示“降落”，无人机开始降落并着陆。

![ROS 降落指令结果](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/ros-command-land.png)

#### 第四步：锁定

:::danger[着陆后才能锁定]

一键锁定为强制指令，飞行过程中触发会导致无人机立即坠落。必须等待无人机着陆后，再执行锁定。

:::

着陆后输入 `d`，再按回车，终端显示“锁定”。完成本轮测试后再继续下发目标点。

![ROS 锁定指令结果](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/ros-command-disarm.png)

### 15. 下发目标点

1. 按第 14 步的方式检查并解锁无人机。
2. 输入 `t` 并回车，一键起飞。
3. 输入数字 `1` 并回车，下发第 8 步设置的第 1 个目标点；同理，输入数字 `4` 并回车，下发第 4 个目标点。
4. 任务完成后输入 `l` 并回车，一键降落。
5. 等待着陆后，输入 `d` 并回车锁定。

指令字符定义在 [fcu_command.cpp](https://github.com/fancinnov/fcu_core/blob/main/src/fcu_command.cpp) 中，可对照源码查看。

### 16. 退出 ROS 工程

退出远程电脑上的 ROS 工程。按材料所引用的退出方式，Windows 使用 `Ctrl + C`，Mac 使用 `Command + C`，再按回车。

### 17. 关闭无人机

无人机锁定后，如果不再继续飞行，及时关闭每台无人机并拔掉电池，避免电量损耗。

## 七、组网配置补充

本节整理原材料第 4 步引用的组网操作，供多机连接时使用。单机使用默认网络时无需执行。

### 1. 连接并打开串口助手

可以使用 Mlink-esp 调试器，或通过飞控的透传模式配置。

#### 方法一：使用 Mlink-esp 调试器

1. 从无人机上取下 Mlink-esp Wi-Fi 模块，连接到配套调试器。注意接口方向，不能接反。
2. 下载并解压 [串口助手 sscom5.13.1](https://fancinnov.com/download/sscom5.13.1%202.rar)，打开 `sscom5.13.1.exe`。
3. 通过 USB 将调试器连接电脑。
4. 在串口助手中选择对应的 `USB-SERIAL CH340` 端口。
5. 按下一节的顺序发送全部 AT 指令，配置路由器信息和该模块的固定 IP。
6. 记录配置结果，完成后将模块装回对应无人机。

#### 方法二：使用飞控透传模式

1. 确保 Mlink-esp 与无人机接插稳定，准备 [固件工程及依赖包](https://fancinnov.com/download-FanciSwarm-after1120)。
2. 在 `Clibrary/include/config.h` 中，将 `#define COMM_0 MAV_COMM` 改为 `#define COMM_0 CONFIG_COMM`。
3. 重新编译，并将生成的 `.hex` 固件烧录到无人机。
4. 下载并打开串口助手。
5. 通过 USB 线将无人机连接到电脑。
6. 在串口助手中选择对应端口。
7. 按下一节顺序发送全部 AT 指令，为当前无人机设置路由器信息和唯一的固定 IP。
8. 配置完成后，将 `COMM_0` 改回 `MAV_COMM`，重新编译并烧录，恢复正常非透传工作模式。
9. 对其他无人机分别完成配置。

透传模式用于通过 USB 向 Mlink-esp 发送配置指令；配置结束后，需要恢复非透传模式。

### 2. 依次发送 AT 指令

下列指令中的 `\r\n` 表示回车换行。路由器名称、密码、固定 IP、网关和子网掩码均按现场网络填写；Wi-Fi 名称不能使用中文。

1. 重启模块：

   ```text
   AT+RST\r\n
   ```

2. 恢复出厂设置：

   ```text
   AT+RESTORE\r\n
   ```

3. 将默认 AP 模式改为 Station 模式：

   ```text
   AT+CWMODE_DEF=1\r\n
   ```

4. 设置路由器名称和密码：

   ```text
   AT+CWJAP_DEF="WiFi名称","WiFi密码"\r\n
   ```

   收到 `WIFI CONNECTED` 表示已连接路由器，收到 `WIFI GOT IP` 表示已分配 IP；未成功时重新检查。

5. 查询当前 IP：

   ```text
   AT+CIFSR\r\n
   ```

6. 设置固定 IP：

   ```text
   AT+CIPSTA_DEF="ip","网关","子网掩码"\r\n
   ```

   各无人机使用不同的 IP，且不得与同一网络内其他设备重复。不要将示例网络地址直接用于不同的现场网络。

7. 再次查询，确认返回地址与设置一致并记录：

   ```text
   AT+CIFSR\r\n
   ```

需要通过 App 检查连接时，手机连接同一路由器，在 App 首页的数传连接入口填写该无人机 IP；之后改用 ROS 时断开 App。
