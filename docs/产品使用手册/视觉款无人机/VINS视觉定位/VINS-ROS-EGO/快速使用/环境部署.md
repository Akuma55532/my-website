# 环境部署

本页介绍 VINS-ROS-EGO 的机载电脑环境、工程安装与开机自启动配置。系统使用 Ubuntu 20.04。

环境准备完成后，继续阅读 [定位与路径规划](./定位与路径规划.md)，选择定位方式、配置参数并进行飞行验证。如遇无法解决的问题，请联系幻思创新工程师协助。

## 一、安装 ROS1

系统已预装 ROS1，无需重复安装。打开终端输入以下命令，检查是否已安装：

```bash
roscore
```

运行结果出现 `started core service`，说明 ROS1 安装成功，可以跳过本节后续安装步骤。

![检查 ROS1 是否已安装](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/ros-core-check.png)

### 1. 配置软件源

在终端执行：

```bash
wget http://fishros.com/install -O fishros && . fishros
```

输入 `5` 并回车，一键配置系统源：

![fishros 主菜单](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/fishros-main-menu.png)

输入 `2` 并回车，更换系统源并清理第三方源：

![更换系统源](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/fishros-system-source.png)

输入 `1` 并回车，添加 ROS/ROS2 源：

![添加 ROS 软件源](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/fishros-add-ros-source.png)

### 2. 安装 ROS

再次运行：

```bash
wget http://fishros.com/install -O fishros && . fishros
```

![选择 ROS 安装选项](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/fishros-main-menu.png)

依次选择 `1（一键安装）` → `不更换源安装` → 对应 Ubuntu 版本的 ROS（本教程选择 ROS1 Noetic）→ `桌面版`。

### 3. 配置 rosdep

```bash
source ~/.bashrc
sudo apt install python3-rosdep python3-rosinstall python3-rosinstall-generator python3-wstool build-essential
sudo rosdep init
rosdep update
```

至此，ROS1 安装完成。

## 四、安装与配置 CUDA

### 1. 添加软件源

```bash
sudo gedit /etc/apt/sources.list.d/nvidia-l4t-apt-source.list
```

添加以下两行：

```text
deb http://repo.download.nvidia.com/jetson/common r35.4 main
deb http://repo.download.nvidia.com/jetson/t234 r35.4 main
```

### 2. 更新软件源

```bash
sudo apt update
```

### 3. 安装 JetPack

```bash
sudo apt install nvidia-jetpack
```

### 4. 配置环境变量

打开配置文件：

```bash
gedit ~/.bashrc
```

在文件末尾添加：

```bash
export LD_LIBRARY_PATH=/usr/local/cuda/lib64
export PATH=/usr/local/cuda/bin:$PATH
export CUDA_HOME=/usr/local/cuda
```

### 5. 加载环境变量

```bash
source ~/.bashrc
```

### 6. 复制 cuDNN 文件

```bash
cd /usr/include && sudo cp cudnn* /usr/local/cuda/include
cd /usr/lib/aarch64-linux-gnu && sudo cp libcudnn* /usr/local/cuda/lib64
```

### 7. 检查 CUDA

```bash
nvcc -V
```

出现下图所示信息，说明 CUDA 安装成功：

![CUDA 版本检查](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/cuda-version-check.png)

### 8. 安装 jtop

jtop 用于查看系统情况。

```bash
sudo apt install python3-pip
sudo -H pip3 install -U pip
sudo -H pip install jetson-stats
```

运行：

```bash
jtop
```

## 五、安装支持 CUDA 的 OpenCV 4.6.0

### 1. 准备源码

下载 [OpenCV 4.6.0](https://github.com/opencv/opencv/releases/tag/4.6.0) 和 [opencv_contrib 4.6.0](https://github.com/opencv/opencv_contrib/releases/tag/4.6.0)。如果网络下载不便，也可以使用幻思提供的库。

将两个压缩包解压到用户主目录。Jetson Orin NX 的 GPU 计算能力为 `8.7`：

![Jetson GPU 计算能力](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/jetson-gpu-compute-capability.png)

### 2. 生成 Makefiles

在用户主目录中打开终端，执行：

```bash
cd opencv-4.6.0/
mkdir build && cd build
```

如果使用幻思提供的库，已有 `build` 文件夹时只需执行 `cd build`。

配置 OpenCV 及其扩展模块：

```bash
cmake -D CMAKE_BUILD_TYPE=RELEASE \
        -D CMAKE_INSTALL_PREFIX=/usr/local/ \
        -D OPENCV_EXTRA_MODULES_PATH=../../opencv_contrib-4.6.0/modules \
        -D WITH_CUDA=ON \
        -D CUDA_ARCH_BIN=8.7 \
        -D CUDA_ARCH_PTX="" \
        -D ENABLE_FAST_MATH=ON \
        -D CUDA_FAST_MATH=ON \
        -D WITH_CUBLAS=ON \
        -D WITH_LIBV4L=ON \
        -D WITH_GSTREAMER=ON \
        -D WITH_GSTREAMER_0_10=OFF \
        -D WITH_QT=ON \
        -D WITH_OPENGL=ON \
        -D CUDA_NVCC_FLAGS="--expt-relaxed-constexpr" \
        -D WITH_TBB=ON \
        ..
```

其中：

- `CMAKE_INSTALL_PREFIX=/usr/local/`：安装目录。
- `OPENCV_EXTRA_MODULES_PATH=../../opencv_contrib-4.6.0/modules`：扩展模块所在路径。
- `CUDA_ARCH_BIN=8.7`：GPU 计算能力。

配置完成后如下图所示：

![OpenCV CMake 配置结果](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/opencv-cmake-result.png)

### 3. 编译安装并检查

```bash
sudo make install -j8
```

安装完成后使用 `jtop` 查看 OpenCV 版本及 CUDA 支持情况：

```bash
jtop
```

![OpenCV CUDA 支持检查](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/opencv-cuda-check.png)

## 七、配置 RealSense 深度相机驱动

### 1. 获取源码

```bash
git clone https://github.com/IntelRealSense/librealsense.git
```

如果下载失败，可以使用幻思提供的库。

### 2. 安装依赖并编译

```bash
cd librealsense
sudo apt-get update
sudo apt-get install git cmake libssl-dev libusb-1.0-0-dev pkg-config libgtk-3-dev
sudo apt-get install libglfw3-dev libgl1-mesa-dev libglu1-mesa-dev
mkdir build
cd build
cmake ../
make -j8
sudo make install
```

使用幻思提供的软件包时，`build` 文件夹已存在，可跳过 `mkdir build`。如果 `cmake ../` 因网络问题未完成，可以重新尝试。

### 3. 配置 USB 规则

```bash
cd ..
sudo cp config/99-realsense-libusb.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules
sudo udevadm trigger
```

### 4. 验证安装

列出相机设备信息，并查看视频流：

```bash
rs-enumerate-devices
realsense-viewer
```

### 5. 安装 Python 包

```bash
pip install pyrealsense2
```

### 6. 编译 RealSense 的 ROS 工程

安装依赖，并进入准备好的 `realsense_ws` 工作空间编译：

```bash
sudo apt-get install ros-noetic-ddynamic-reconfigure
cd realsense_ws
catkin_make
```

### 7. 启动相机 ROS 工程

在 `realsense_ws` 工作空间执行：

```bash
source devel/setup.bash
roslaunch realsense2_camera rs_camera.launch
```

### 1. 安装 Ceres Solver 1.14.0

下载并解压源码：

```bash
wget ceres-solver.org/ceres-solver-1.14.0.tar.gz
tar -zxvf ceres-solver-1.14.0.tar.gz
```

安装 glog、gflags、ATLAS 和 Eigen3：

```bash
sudo apt-get install libgoogle-glog-dev libgflags-dev

```

编译安装：

```bash
cd ~/ceres-solver-1.14.0
mkdir build && cd build
cmake ..
sudo make install -j8
```

如果提供的库中已有 `build` 文件夹，只需进入该目录。

```bash
mkdir -p ~/vins-fusion-gpu/src/
cd ~/vins-fusion-gpu/src/
```

如果直接使用幻思提供的 `vins-fusion-gpu` 工程，无需进行下面的源码配置和兼容性修改，可以直接进入工作空间编译：

## 十、全部工程自动运行

### 1. 配置串口权限

在 `70-ttyusb.rules` 所在目录执行：

```bash
sudo cp 70-ttyusb.rules /etc/udev/rules.d/
```

重启后生效。

### 2. 运行启动脚本

在 `auto_ap.sh` 所在目录执行：

```bash
sh auto_ap.sh
```

:::caution[机载 VINS RViz 仅用于静态测试]

提供的脚本已注释最后一段启动 VINS RViz 界面的程序，因为它会影响 VINS 的实时性。只有静态测试时可以运行这一段；飞行过程中必须保持注释，禁止运行。

:::

## 十一、配置开机自启动

### 1. 开启 Ubuntu 自动登录

![Ubuntu 自动登录设置](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/ubuntu-auto-login.png)

### 2. 核对启动脚本路径

检查 `auto_ap.sh` 中的工程路径是否与实际位置一致，不一致时改为实际路径。

### 3. 测试启动脚本

在终端执行 `sh auto_ap.sh`，检查 SLAM 工程是否在一分钟内正常启动。

### 4. 添加启动项

打开应用程序菜单：

![打开 Ubuntu 应用程序菜单](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/ubuntu-applications.png)

搜索并打开 Startup Applications：

![搜索 Startup Applications](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/startup-applications-search.png)

点击 `Add`：

![添加启动项](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/startup-applications-add.png)

填写 Name，点击 `Browse` 选择 `auto_ap.sh`。选好后，在 Command 栏的文件路径前加上 `sh `，注意保留空格。例如：

```bash
sh /xxxx/auto_ap.sh
```

`/xxxx/auto_ap.sh` 为示例，实际填写所选脚本的完整路径。

![选择自启动脚本](/产品使用手册/使用手册/视觉套件/VINS-ROS-EGO/startup-script-select.png)

### 5. 设置功率并验证

按照材料要求，将 Jetson NX 的功率模式设置为 `MAXN`。重启系统，检查 SLAM 界面是否在开机一分钟内正常运行。

此时尚不会出现点云地图，需要继续完成 [定位与路径规划](./定位与路径规划.md) 中的飞控串口波特率设置。
