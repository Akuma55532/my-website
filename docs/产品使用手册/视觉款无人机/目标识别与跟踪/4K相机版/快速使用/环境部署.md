# 环境部署

本页介绍 FanciSwarm Pro 搭载 4K 云台相机所需的环境配置。

## 一、文件准备

- [YOLO 文件包](https://pan.baidu.com/s/1V21GBuy0VMleXegQqPFqcA)，提取码：`jfjq`。
- [r8125 网卡驱动](https://fancinnov.com/file3/r8125-9.015.00.tar.bz2)。
- [4K 云台相机专属 yolov5_det_trt.py](https://fancinnov.com/file3/yolov5_det_trt.py)。

YOLO 文件包内容如下：

```text
20.04-yolo
├─ 70-ttyusb.rules
├─ auto_ap.sh
├─ datalink_serial.py
├─ mavcrc.py
├─ mavcrc.pyc
├─ mavlink.py
├─ mavlink.pyc
├─ opencv-4.6.0.zip
├─ opencv_contrib-4.6.0.zip
├─ tensorrtx.zip
├─ torch-2.1.0a0+41361538.nv23.06-cp38-cp38-linux_aarch64.whl
├─ vision-release-0.16.zip
├─ yolov5.zip
└─ yolov5_det_trt.py
```

## 二、ROS1 安装

系统已预装 ROS1，无需重复安装，可以跳过本节安装步骤。打开终端，输入以下命令确认：

```bash
roscore
```

运行结果如下图所示：

![ROS1 运行结果](/产品使用手册/使用手册/视觉套件/4K相机/A8mini_files/ros1-core.png)

如需安装，使用 fishros 一键环境配置工具安装 ROS1 Noetic。

### 1. 配置软件源

在终端输入：

```bash
wget http://fishros.com/install -O fishros && . fishros
```

出现以下界面后，选择 `5`，更新系统源：

![fishros 主菜单](/产品使用手册/使用手册/视觉套件/4K相机/A8mini_files/JetsonNXBaseEnv1.png)

接下来选择 `2`：

![系统源配置选项](/产品使用手册/使用手册/视觉套件/4K相机/A8mini_files/JetsonNXBaseEnv2.png)

然后选择 `1`，添加 ROS 源：

![添加 ROS 源](/产品使用手册/使用手册/视觉套件/4K相机/A8mini_files/JetsonNXBaseEnv3.png)

### 2. 安装 ROS1 Noetic

再次执行：

```bash
wget http://fishros.com/install -O fishros && . fishros
```

![fishros 安装菜单](/产品使用手册/使用手册/视觉套件/4K相机/A8mini_files/JetsonNXBaseEnv1.png)

依次选择：`1（一键安装）` → `不更换源安装` → 对应 Ubuntu 版本的 ROS（此处选择 ROS1 Noetic）→ `桌面版`。

### 3. 配置 rosdep

```bash
source ~/.bashrc
sudo apt install python3-rosdep python3-rosinstall python3-rosinstall-generator python3-wstool build-essential
sudo rosdep init
rosdep update
```

执行完成后，rosdep 配置完毕。

## 四、安装与配置 CUDA

### 1. 添加软件源

打开软件源配置文件：

```bash
sudo gedit /etc/apt/sources.list.d/nvidia-l4t-apt-source.list
```

添加以下两行：

```text
deb http://repo.download.nvidia.com/jetson/common r35.4 main
deb http://repo.download.nvidia.com/jetson/t234 r35.4 main
```

### 2. 更新软件包与软件源

```bash
sudo apt upgrade
sudo apt update
```

### 3. 安装 JetPack

```bash
sudo apt install nvidia-jetpack
```

### 4. 配置环境变量

打开配置文件：

```bash
gedit ~/.bashrc
```

在文件末尾添加：

```bash
export LD_LIBRARY_PATH=/usr/local/cuda/lib64
export PATH=/usr/local/cuda/bin:$PATH
export CUDA_HOME=/usr/local/cuda
```

加载环境变量：

```bash
source ~/.bashrc
```

### 5. 复制 cuDNN 文件

```bash
cd /usr/include && sudo cp cudnn* /usr/local/cuda/include
cd /usr/lib/aarch64-linux-gnu && sudo cp libcudnn* /usr/local/cuda/lib64
```

### 6. 检查 CUDA

```bash
nvcc -V
```

出现下图所示信息，表示 CUDA 安装成功：

![CUDA 安装检查](/产品使用手册/使用手册/视觉套件/4K相机/A8mini_files/JetsonNXBaseEnv4.png)

### 7. 安装 jtop

jtop 用于查看系统运行情况。

```bash
sudo apt install python3-pip
sudo -H pip3 install -U pip
sudo -H pip install jetson-stats
```

重启后执行：

```bash
jtop
```

## 五、安装支持 CUDA 加速的 OpenCV 4.6.0

### 1. 准备 OpenCV 与扩展模块

- [OpenCV 4.6.0](https://github.com/opencv/opencv/releases/tag/4.6.0)
- [opencv_contrib 4.6.0](https://github.com/opencv/opencv_contrib/releases/tag/4.6.0)

如果网络下载不便，也可以使用幻思提供的文件包。将两个压缩包都解压到用户主目录。

Jetson Orin NX 的 GPU 计算能力为 `8.7`，如下图所示：

![Jetson Orin NX GPU 计算能力](/产品使用手册/使用手册/视觉套件/4K相机/A8mini_files/JetsonNXBaseEnv5.png)

### 2. 配置编译选项

在用户主目录下打开终端，进入 OpenCV 目录并创建 `build` 文件夹：

```bash
cd opencv-4.6.0/
mkdir build && cd build
```

如果使用幻思提供的库，已有 `build` 文件夹时，只需执行 `cd build`。使用该库前，先清除 `build` 文件夹内的缓存文件，并确认 `opencv-4.6.0` 和 `opencv_contrib-4.6.0` 均已解压到用户主目录，再执行以下命令生成 Makefiles：

```bash
cmake -D CMAKE_BUILD_TYPE=RELEASE \
        -D CMAKE_INSTALL_PREFIX=/usr/local/ \
        -D OPENCV_EXTRA_MODULES_PATH=../../opencv_contrib-4.6.0/modules \
        -D WITH_CUDA=ON \
        -D CUDA_ARCH_BIN=8.7 \
        -D CUDA_ARCH_PTX="" \
        -D ENABLE_FAST_MATH=ON \
        -D CUDA_FAST_MATH=ON \
        -D WITH_CUBLAS=ON \
        -D WITH_LIBV4L=ON \
        -D WITH_GSTREAMER=ON \
        -D WITH_GSTREAMER_0_10=OFF \
        -D WITH_QT=ON \
        -D WITH_OPENGL=ON \
        -D CUDA_NVCC_FLAGS="--expt-relaxed-constexpr" \
        -D WITH_TBB=ON \
        ..
```

其中：

- `CMAKE_INSTALL_PREFIX=/usr/local/`：安装目录。
- `OPENCV_EXTRA_MODULES_PATH=../../opencv_contrib-4.6.0/modules`：扩展模块所在路径。
- `CUDA_ARCH_BIN=8.7`：GPU 计算能力。

配置完成后如下图所示：

![OpenCV 配置结果](/产品使用手册/使用手册/视觉套件/4K相机/A8mini_files/JetsonNXBaseEnv6.png)

### 3. 编译安装与检查

编译安装 OpenCV 及其扩展模块，过程较长，请耐心等待：

```bash
sudo make install -j8
```

安装完成后，运行 `jtop` 查看 OpenCV 版本及 CUDA 支持情况：

```bash
jtop
```

![OpenCV 安装检查](/产品使用手册/使用手册/视觉套件/4K相机/A8mini_files/JetsonNXBaseEnv7.png)

## 六、YOLOv5 配置

### 1. 安装 PyTorch 与 torchvision

在准备好的文件所在目录执行：

```bash
sudo pip3 install torch-2.1.0a0+41361538.nv23.06-cp38-cp38-linux_aarch64.whl
sudo apt-get install libopenblas-dev

cd vision-release-0.16
export BUILD_VERSION=0.16
python setup.py install --user
cd ..
```

进入 Python，检查 PyTorch 与 torchvision 的版本：

```pycon
$ python3
>>> import torch
>>> import torchvision
>>> print(torch.__version__)
>>> print(torchvision.__version__)
```

能够正常输出版本，说明安装成功。

### 2. 安装依赖并准备工程

```bash
pip install tqdm
pip install Ipython
pip install seaborn
git clone -b v7.0 https://github.com/ultralytics/yolov5.git
git clone -b yolov5-v7.0 https://github.com/wang-xinyu/tensorrtx.git
```

如果通过 Git 下载这两个工程，需要将幻思文件包中的 `.py` 和 `.pyc` 文件复制到 `tensorrtx/yolov5/` 文件夹。如果直接使用幻思文件包中的工程，则无需复制。

确保 NumPy 版本为 `1.23.0`：

```bash
pip install numpy==1.23.0
```

### 3. 生成权重文件

```bash
cd yolov5/
wget https://github.com/ultralytics/yolov5/releases/download/v7.0/yolov5s.pt
cp ~/tensorrtx/yolov5/gen_wts.py .
pip install numpy==1.20.3
python gen_wts.py -w yolov5s.pt -o yolov5s.wts
pip install numpy==1.23.0
```

执行完成后会生成 `yolov5s.wts` 文件。

### 4. 构建 TensorRT 引擎

```bash
cd ~/tensorrtx/yolov5/
mkdir build
cd build
cp ~/yolov5/yolov5s.wts .
cmake ..
make
./yolov5_det -s yolov5s.wts yolov5s.engine s
```

如果使用幻思提供的 TensorRTx 包，已有 `build` 文件夹时直接进入即可；按照材料中的说明，建议先清空该文件夹内的旧构建文件，再复制权重文件并执行 `cmake ..`。

### 5. 安装运行依赖并设置串口权限

```bash
pip install pycuda
pip install pyserial
cd ~/tensorrtx/yolov5
sudo chmod 777 /dev/ttyTHS0
```

将 Jetson 电源模式调整为 `MAXN`。

## 七、开启网口 1

下载 [r8125 网卡驱动](https://fancinnov.com/file3/r8125-9.015.00.tar.bz2)，将文件移动到 Jetson NX，在文件所在目录解压：

```bash
tar vjxf r8125-9.015.00.tar.bz2
```

进入解压后的驱动文件夹，在该目录的终端执行：

```bash
sudo ./autorun.sh
```

在系统设置（Settings）的 Network 项中查看网口。如果出现 `eth1`，说明开启成功。

完成环境配置后，继续阅读 [识别跟踪](./识别跟踪.md)。
