# 识别跟踪

本页介绍 4K 云台相机识别程序的运行、自启动配置及跟踪参数。所需软件和工程的配置见 [环境部署](./环境部署.md)。

## 一、替换云台相机专属脚本并运行

下载 [4K 云台相机专属 yolov5_det_trt.py](https://fancinnov.com/file3/yolov5_det_trt.py)，替换 `~/tensorrtx/yolov5/` 文件夹中的同名文件。

在该文件夹的终端中执行：

```bash
python3 yolov5_det_trt.py
```

程序默认检测人体，出现检测效果即表示运行成功。

## 二、全部工程自动运行

### 1. 配置串口权限

在 `70-ttyusb.rules` 所在目录执行以下命令，将权限配置文件复制到 `/etc/udev/rules.d/`：

```bash
sudo cp 70-ttyusb.rules /etc/udev/rules.d/
```

重启后生效。

### 2. 运行启动脚本

在 `auto_ap.sh` 所在目录执行：

```bash
sh auto_ap.sh
```

## 四、自定义参数说明

以下参数位于 `yolov5_det_trt.py`，可结合实际识别目标和使用情况调整。

### 1. 图像、目标与跟踪参数

```python
W_img = 1280 # 图像宽度,默认1280x720
H_img = 720 # 图像高度
FOV_x = 81  # 水平视场角，度
FOV_y = 45  # 垂直视场角，度
W_real = 0.8  # target实际宽度，米
H_real = 1.7  # target实际高度，米
safe_distance = 1.5  # 跟踪间距
width_up_threshold = 0.5  # 目标宽度上限阈值，比例
width_down_threshold = 0.25  # 目标宽度下限阈值
k = 1.0  # 系数
Kp_dx = 0.5
Kp_dy = 0.5
Kp_dalt = 0.5
Kp_dyaw = 0.3
```

- `FOV_x`、`FOV_y`：用于单目测距的水平、垂直视场角，根据云台相机内参确定，一般无需更改。
- `W_real`、`H_real`：识别目标的实际宽度和高度。默认识别人体，因此示例值分别为宽 `0.8 m`、高 `1.7 m`，并非所有目标都使用这组尺寸。
- `safe_distance`：跟踪过程中与目标保持的距离。
- `width_up_threshold`、`width_down_threshold`：为改善识别效果设置的目标宽度上下限阈值，可根据实际情况调整。
- `k` 及 `Kp_dx`、`Kp_dy`、`Kp_dalt`、`Kp_dyaw`：跟踪过程中的比例调节参数。

### 2. 识别置信度

```python
CONF_THRESH = 0.5
```

`CONF_THRESH` 为 YOLO 识别置信度阈值。

### 3. 参数应用片段

下面的代码摘自材料中的 `yolov5_det_trt.py`，用于对照上述参数在程序中的使用位置：

```python
        for j in range(len(result_boxes)):
            box = result_boxes[j]
            if result_scores[j]>0.5 and categories[int(result_classid[j])]=='person':
                # 计算相机的焦距 f，单位为像素
                f_x = (W_img / 2) / np.tan(np.radians(FOV_x / 2))
                f_y = (H_img / 2) / np.tan(np.radians(FOV_y / 2))
                x1=box[0]
                y1=box[1]
                x2=box[2]
                y2=box[3]
                W_qr = x2 - x1
                H_qr = y2 - y1

                cx_qr = (x1 + x2) / 2
                cy_qr = (y1 + y2) / 2

                cx_img = W_img / 2
                cy_img = H_img / 2

                dx = cx_qr - cx_img
                dy = cy_qr - cy_img

                angle_x_rad = k * np.arctan(dx / f_x)
                dz_m = k * (W_real * f_x) / W_qr
                dy_m = k * (dy / f_y) * dz_m
                dx_m = k * (dx / f_x) * dz_m

                dx_1 = dz_m - safe_distance
                dy_1 = dx_m
                d_alt_1 = -dy_m
                d_yaw = angle_x_rad

                if W_qr > width_up_threshold * W_img or W_qr < width_down_threshold * W_img:
                    dx_1 = 0.0

                dl.set_pose(Kp_dx * dx_1, Kp_dy * dy_1, Kp_dalt * d_alt_1, Kp_dyaw * d_yaw)
                plot_one_box(
                    box,
                    image_raw,
                    label="{}:{:.2f}".format(
                        categories[int(result_classid[j])], result_scores[j]
                    ),
                )
        return image_raw, end - start
```
