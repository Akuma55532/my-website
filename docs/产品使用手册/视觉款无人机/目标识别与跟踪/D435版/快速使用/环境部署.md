# 环境部署

本页介绍 D435 版目标识别与跟踪所需的 Jetson NX 基础环境、深度相机驱动，以及视频流接收端的环境配置。

材料中的实验平台为 FanciSwarm 机载电脑无人机，系统为 Ubuntu 20.04 LTS。

## 一、文件准备

下载 [20.04-rs-yolo.zip](https://pan.baidu.com/s/1uyfZj4AW0vSOlq7k8Tby4g)，提取码：`g3w6`。

```text

├─ auto_ap.sh
├─ librealsense.zip

├─ opencv_contrib-4.6.0.zip

├─ vision-release-0.16.zip
└─ yolov5.zip
```

## 四、安装与配置 CUDA

### 1. 添加软件源

打开配置文件：

```bash
sudo gedit /etc/apt/sources.list.d/nvidia-l4t-apt-source.list
```

添加以下两行：

```text
deb http://repo.download.nvidia.com/jetson/common r35.4 main
deb http://repo.download.nvidia.com/jetson/t234 r35.4 main
```

### 2. 更新软件包与软件源

```bash
sudo apt upgrade
sudo apt update
```

### 3. 安装 JetPack

```bash
sudo apt install nvidia-jetpack
```

### 4. 配置环境变量

打开配置文件：

```bash
gedit ~/.bashrc
```

在文件末尾添加：

```bash
export LD_LIBRARY_PATH=/usr/local/cuda/lib64
export PATH=/usr/local/cuda/bin:$PATH
export CUDA_HOME=/usr/local/cuda
```

加载环境变量：

```bash
source ~/.bashrc
```

### 5. 复制 cuDNN 文件

```bash
cd /usr/include && sudo cp cudnn* /usr/local/cuda/include
cd /usr/lib/aarch64-linux-gnu && sudo cp libcudnn* /usr/local/cuda/lib64
```

### 6. 检查 CUDA

```bash
nvcc -V
```

出现下图所示信息，表示 CUDA 安装成功：

![CUDA 安装检查](</产品使用手册/使用手册/视觉套件/D435版/幻思创新——无人机目标识别与跟踪开发指南(D435版)_files/JetsonNXBaseEnv4.png>)

### 7. 安装 jtop

jtop 用于查看系统运行情况。

```bash
sudo apt install python3-pip
sudo -H pip3 install -U pip
sudo -H pip install jetson-stats
```

重启后运行：

```bash
jtop
```

## 五、安装支持 CUDA 加速的 OpenCV 4.6.0

### 1. 准备 OpenCV 与扩展模块

- [OpenCV 4.6.0](https://github.com/opencv/opencv/releases/tag/4.6.0)
- [opencv_contrib 4.6.0](https://github.com/opencv/opencv_contrib/releases/tag/4.6.0)

如果网络下载不便，也可以使用幻思提供的文件包。将两个压缩包解压到用户主目录。

Jetson Orin NX 的 GPU 计算能力为 `8.7`，如下图所示：

![Jetson Orin NX GPU 计算能力](</产品使用手册/使用手册/视觉套件/D435版/幻思创新——无人机目标识别与跟踪开发指南(D435版)_files/JetsonNXBaseEnv5.png>)

### 2. 配置编译选项

在用户主目录下打开终端，进入 OpenCV 目录：

```bash
cd opencv-4.6.0/
mkdir build && cd build
```

如果使用幻思提供的库，已有 `build` 文件夹时，只需执行 `cd build`。根据本版材料，使用提供的库可以直接执行下一步的 `sudo make install -j8`。

自行配置时，执行以下命令，为 OpenCV 及其扩展模块生成 Makefiles：

```bash
cmake -D CMAKE_BUILD_TYPE=RELEASE \
        -D CMAKE_INSTALL_PREFIX=/usr/local/ \
        -D OPENCV_EXTRA_MODULES_PATH=../../opencv_contrib-4.6.0/modules \
        -D WITH_CUDA=ON \
        -D CUDA_ARCH_BIN=8.7 \
        -D CUDA_ARCH_PTX="" \
        -D ENABLE_FAST_MATH=ON \
        -D CUDA_FAST_MATH=ON \
        -D WITH_CUBLAS=ON \
        -D WITH_LIBV4L=ON \
        -D WITH_GSTREAMER=ON \
        -D WITH_GSTREAMER_0_10=OFF \
        -D WITH_QT=ON \
        -D WITH_OPENGL=ON \
        -D CUDA_NVCC_FLAGS="--expt-relaxed-constexpr" \
        -D WITH_TBB=ON \
        ..
```

其中：

- `CMAKE_INSTALL_PREFIX=/usr/local/`：安装目录。
- `OPENCV_EXTRA_MODULES_PATH=../../opencv_contrib-4.6.0/modules`：扩展模块所在路径。
- `CUDA_ARCH_BIN=8.7`：GPU 计算能力。

配置完成后如下图所示：

![OpenCV 配置结果](</产品使用手册/使用手册/视觉套件/D435版/幻思创新——无人机目标识别与跟踪开发指南(D435版)_files/JetsonNXBaseEnv6.png>)

### 3. 编译安装与检查

编译安装 OpenCV 及其扩展模块，过程较长，请耐心等待：

```bash
sudo make install -j8
```

安装完成后运行 `jtop` 查看版本：

```bash
jtop
```

![OpenCV 安装检查](</产品使用手册/使用手册/视觉套件/D435版/幻思创新——无人机目标识别与跟踪开发指南(D435版)_files/JetsonNXBaseEnv7.png>)

## 六、配置 RealSense 深度相机驱动

如果已经安装 RealSense 驱动，可以跳过本节。

### 1. 获取源码

```bash
git clone https://github.com/IntelRealSense/librealsense.git
```

如果下载失败，可以使用幻思文件包中的 `librealsense.zip`。

### 2. 安装依赖并编译

```bash
cd librealsense
sudo apt-get update
sudo apt-get install git cmake libssl-dev libusb-1.0-0-dev pkg-config libgtk-3-dev libglfw3-dev libgl1-mesa-dev libglu1-mesa-dev
mkdir build
cd build
cmake ../
make -j4
sudo make install
```

使用幻思提供的软件包时，`build` 文件夹已存在，可跳过 `mkdir build`。如果 `cmake ../` 因网络问题未完成，可以重新尝试。

### 3. 配置 USB 规则

从 `build` 返回 `librealsense` 目录后执行：

```bash
cd ..
sudo cp config/99-realsense-libusb.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules
sudo udevadm trigger
```

### 4. 验证安装

列出设备信息：

```bash
rs-enumerate-devices
```

查看视频流：

```bash
realsense-viewer
```

### 5. 安装 Python 包

```bash
pip install pyrealsense2
```

## 七、YOLOv5 环境配置

### 1. 安装 PyTorch 与 torchvision

在准备好的文件所在目录执行：

```bash
sudo pip3 install torch-2.1.0a0+41361538.nv23.06-cp38-cp38-linux_aarch64.whl
sudo apt-get install libopenblas-dev

cd vision-release-0.16
export BUILD_VERSION=0.16
python setup.py install --user
cd ..
```

进入 Python，检查 PyTorch 与 torchvision：

```pycon
$ python3
>>> import torch
>>> import torchvision
>>> print(torch.__version__)
>>> print(torchvision.__version__)
```

能够正常导入、输出版本且无报错，说明安装成功。

### 2. 安装运行依赖

```bash
pip install tqdm
pip install Ipython
pip install seaborn
pip install numpy==1.23.0
pip install pycuda
pip install pyserial
```

至此，Jetson NX 基础环境配置完成。工程准备和运行步骤见 [识别跟踪](./识别跟踪.md)。

## 八、视频流接收端环境

材料中的独立视频流示例通过 TCP 将 Jetson NX 的 CSI 摄像头画面传输到 PC。YOLO 检测程序本身也带有视频流传输功能，两者使用的端口均为 `5005`。

下载对应脚本：

- Jetson NX 端：[TcpNoDelay_transtream_NX.py](https://fancinnov.com/file2/TcpNoDelay_transtream_NX.py)。
- PC 端：[TcpNoDelay_recvstream_PC.py](https://fancinnov.com/file2/TcpNoDelay_recvstream_PC.py)。

Jetson NX 端使用前面配置好的基础环境。PC 端使用 Python `3.10`，安装以下依赖：

```bash
pip install opencv-contrib-python==4.6.0.66
pip install numpy==1.24.0
```

原文的 PC 端示例还调用了 FFmpeg 提供的 `ffplay`，需在 PC 端准备该程序；材料未提供其安装步骤。视频流的运行方法见 [识别跟踪中的视频流传输](./识别跟踪.md#五视频流传输)。

## 九、识别跟踪接入 ROS 的工程配置

本节用于通过 ROS 接入识别跟踪的场景，使用的工程为 `fcu_core_v2`，不兼容第一版 `fcu_core`。

### 1. 创建工作空间并获取工程

```bash
mkdir -p ~/ros_ws/src
cd ~/ros_ws/src
git clone https://github.com/fancinnov/fcu_core_v2.git
git clone https://github.com/fancinnov/quadrotor_msgs.git
```

### 2. 配置 launch 参数

- `channel` 设置为 `0`，表示使用串口通信。
- `offboard` 设置为 `true`，表示由机载电脑进行 offboard 控制。

材料中的配置示例如下：

```xml
    <node pkg="fcu_core" type="fcu_bridge_001" name="fcu_bridge_001" output="screen">
        <remap from="~odometry_001" to="Odometry"/>
        <remap from="~imu_global_001" to="imu_global_001"/>
        <remap from="~odom_global_001" to="odom_global_001"/>
        <remap from="~path_global_001" to="path_global_001"/>
        <remap from="~path_target_001" to="path_target_001"/>
        <remap from="~goal_001" to="/move_base_simple/goal"/>
        <remap from="~motion_001" to="motion_001"/>
        <remap from="~command" to="/fcu_command/command"/>
        <remap from="~mission_001" to="/fcu_mission/mission_001"/>
        <param name="DRONE_IP" value="192.168.4.1" type="string"/>
        <param name="USB_PORT" value="/dev/ttyTHS0" type="string"/>
        <param name="channel" value="0"/>
        <param name="offboard" value="true" type="bool"/>
        <param name="use_uwb" value="false" type="bool"/>
        <param name="set_goal" value="false" type="bool"/>
        <param name="simple_target" value="true" type="bool"/>
        <param name="odom_init_x" value="0.0"/> <!-- FLU 坐标系 -->
        <param name="odom_init_y" value="0.0"/>
        <param name="odom_init_z" value="0.0"/>
    </node>
```

脚本替换和接入说明见 [识别跟踪中的 ROS 接入](./识别跟踪.md#六识别跟踪接入-ros)。
