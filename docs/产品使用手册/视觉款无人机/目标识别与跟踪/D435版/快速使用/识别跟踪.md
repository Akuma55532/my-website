# 识别跟踪

本页介绍 D435 版 YOLOv5 程序运行、模型更换、自启动、视频流传输和 ROS 接入。所需软件配置见 [环境部署](./环境部署.md)。

## 一、运行 YOLOv5 程序

### 1. 配置串口权限

运行前执行以下串口权限命令。需要重启后生效的权限配置，见本页“全部工程自动运行”一节。

```bash
sudo chmod 777 /dev/ttyTHS0
```

### 2. 准备工程

使用幻思文件包中的工程，将 `tensorrtx` 和 `yolov5` 解压到 `/home/nv` 目录下。

### 3. 生成 WTS 文件

WTS 是生成 Engine 文件所需的中间文件。在 `/home/nv` 目录下打开终端，执行：

```bash
cd ./yolov5
wget https://github.com/ultralytics/yolov5/releases/download/v7.0/yolov5s.pt
cp ~/tensorrtx/yolov5/gen_wts.py .
pip install numpy==1.20.3
python gen_wts.py -w yolov5s.pt -o yolov5s.wts
pip install numpy==1.23.0
```

### 4. 生成 Engine 文件

```bash
cd ~/tensorrtx/yolov5/
mkdir build
cd build
cp ~/yolov5/yolov5s.wts .
cmake ..
make
./yolov5_det -s yolov5s.wts yolov5s.engine s
cd ~/tensorrtx/yolov5
sudo chmod 777 /dev/ttyTHS0
```

如果使用提供的 TensorRTx 包，已有 `build` 文件夹时直接进入即可。材料建议先清空该文件夹中的旧构建文件，再复制权重文件并执行 `cmake ..`。

### 5. 运行识别程序

将 Jetson 电源模式调整为 `MAXN`，在 `~/tensorrtx/yolov5` 目录下执行：

```bash
python yolov5_det_trt_rs.py
```

## 二、更换模型文件

材料提供了以下模型文件，可以使用其中的 WTS 文件直接生成 Engine 文件：

- [person.wts](https://fancinnov.com/file2/person.wts)
- [person.pt](https://fancinnov.com/file2/person.pt)

### 1. 清理旧构建文件

删除 `tensorrtx/yolov5/build/` 文件夹中的原有文件。

### 2. 修改模型类别数量

打开 `tensorrtx/yolov5/src/config.h`，将 `kNumClass` 改为训练模型的类别数量。提供的 `person` 模型包含 6 类，对应配置如下：

```cpp
constexpr static int kNumClass = 6; // 更改成训练模型的类别数量(我们提供的person模型的类别为6种)
```

### 3. 编译并生成 Engine 文件

在 `tensorrtx/yolov5/` 目录下执行：

```bash
cd build && cmake .. && make
```

将下载的 `person.wts` 放到当前 `build` 目录，再执行：

```bash
./yolov5_det -s person.wts person.engine s
```

### 4. 修改程序中的模型路径

打开 `yolov5_det_trt_rs.py`，找到模型文件路径配置（材料中位于第 640 行），修改为：

```python
engine_file_path = "./build/person.engine"
```

在 `70-ttyusb.rules` 所在目录执行以下命令，将串口权限配置文件复制到 `/etc/udev/rules.d/`：


### 3. 原文程序片段

以下保留材料中的视频流程序片段及说明，便于对照配置。

#### Jetson NX 端

导入库并设置全局参数。`TCP_IP = '0.0.0.0'` 表示监听所有本地网络接口上的连接：

```python
import socket
import cv2
import numpy as np

# 配置
TCP_IP = '0.0.0.0'
TCP_PORT = 5005
```

`gstreamer_pipeline` 函数根据传入参数生成 GStreamer 管道字符串，用于配置摄像头输入和输出画面。将该字符串传给 `cv2.VideoCapture`，再创建服务器套接字：

```python
def gstreamer_pipeline(
    sensor_id=0,
    capture_width=1920,
    capture_height=1080,
    display_width=960,
    display_height=540,
    framerate=30,
    flip_method=0,
):
    return (
        "nvarguscamerasrc sensor-id=%d ! "
        "video/x-raw(memory:NVMM), width=(int)%d, height=(int)%d, framerate=(fraction)%d/1 ! "
        "nvvidconv flip-method=%d ! "
        "video/x-raw, width=(int)%d, height=(int)%d, format=(string)BGRx ! "
        "videoconvert ! "
        "video/x-raw, format=(string)BGR ! appsink"
        % (
            sensor_id,
            capture_width,
            capture_height,
            framerate,
            flip_method,
            display_width,
            display_height,
        )
    )

# 初始化摄像头
cap = cv2.VideoCapture(gstreamer_pipeline(flip_method=2), cv2.CAP_GSTREAMER)
if not cap.isOpened():
    print("无法打开摄像头，尝试使用默认摄像头设备")
    cap = cv2.VideoCapture(0)

# 创建服务器套接字
sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
sock.bind((TCP_IP, TCP_PORT))
sock.listen(1)
print(f"服务器已启动，监听 {TCP_IP}:{TCP_PORT}")
```

程序循环读取摄像头画面，将图像编码并转换为字节数据，再通过 TCP 发送：

```python
try:
    while True:
        print("等待客户端连接...")
        conn, addr = sock.accept()
        print(f"客户端已连接：{addr}")
        conn.setsockopt(socket.IPPROTO_TCP, socket.TCP_NODELAY, 1)

        try:
            while True:
                ret, frame = cap.read()
                if not ret:
                    print("无法读取摄像头画面")
                    break

                # 编码为JPEG
                encode_param = [int(cv2.IMWRITE_JPEG_QUALITY), 70]
                result, img_encoded = cv2.imencode('.jpg', frame, encode_param)
                if not result:
                    continue

                data = img_encoded.tobytes()

                # 发送图像大小（4字节）
                conn.sendall(len(data).to_bytes(4, 'big'))

                # 发送图像数据
                conn.sendall(data)

                # 显示本地画面（可选）
                cv2.imshow('Sending Image', frame)
                if cv2.waitKey(1) == 27:  # 按 ESC 退出
                    raise KeyboardInterrupt

        except (BrokenPipeError, ConnectionResetError) as e:
            print(f"[错误] 客户端断开连接: {e}")
        finally:
            conn.close()
            print("客户端连接已关闭，等待新连接...")

except KeyboardInterrupt:
    print("服务器正在关闭...")

finally:
    cap.release()
    cv2.destroyAllWindows()
    sock.close()
    print("所有资源已释放")
```

#### PC 端

导入所需库：

```python
import cv2
import numpy as np
import subprocess
from multiprocessing import Array
```

材料中的接收端示例调用 `ffplay`，并通过 `video_display` 函数读取数据、复制到共享内存和显示画面。`ffplay` 由 FFmpeg 提供。

```python
def video_display(ffmpeg_command, frame_array, W_img, H_img):
    process = subprocess.Popen(ffmpeg_command, stdout=subprocess.PIPE)
    
    while True:
        raw_frame = process.stdout.read(W_img * H_img * 3)  # RGB 3 channels
        if not raw_frame:
            break

        # 将帧复制到共享内存中
        frame = np.frombuffer(raw_frame, dtype=np.uint8).reshape(H_img, W_img, 3)
        np.copyto(np.frombuffer(frame_array.get_obj(), dtype=np.uint8).reshape(H_img, W_img, 3), frame)

        # 显示帧
        cv2.imshow('Real-Time Video', frame)

        if cv2.waitKey(1) & 0xFF == ord('q'):
            break

    cv2.destroyAllWindows()
    process.terminate()

if __name__ == '__main__':
    W_img = 640
    H_img = 480

    shared_frame = Array('B', W_img * H_img * 3)  # RGB 3通道，大小为像素数 × 3

    ffmpeg_command = [
        'ffplay',
        '-i', 'tcp://192.168.0.112:5005', # 这里的地址要使用JetsonNX的地址，需要自行替换。
        '-vf', 'setpts=N/30',
        '-fflags', 'nobuffer',
        '-flags', 'low_delay',
        '-framedrop'
    ]

    video_display(ffmpeg_command, shared_frame, W_img, H_img)
```

## 六、识别跟踪接入 ROS

本节使用的 ROS 工程是 `fcu_core_v2`，不兼容第一版 `fcu_core`。

前面的识别程序在 Ubuntu 20.04 的 Python 环境下直接与飞控通信。本节将 `yolov5_det_trt_rs.py` 接入 ROS，通过 ROS 与上位机、飞控协同控制：

- 由 `fcu_core_v2` 工程中的 `fcu_core` 统一管理 Jetson NX 与飞控之间的通信。
- 复用并扩展 `fcu_core_v2` 的功能，实现远程开启、关闭识别跟踪，并支持多节点协同，提高系统的可靠性、兼容性与可扩展性。

先完成 [ROS 工程配置](./环境部署.md#九识别跟踪接入-ros-的工程配置)。

### 1. 替换 ROS 版脚本

材料提供了已修改好的 [yolov5_det_trt_rs(ros).py](<https://fancinnov.com/file/yolov5_det_trt_rs(ros).py>)，将其替换至 `tensorrtx/yolov5/` 对应位置。

### 2. 原文 ROS 接入片段

以下保留材料中的接入要点，用于对照 ROS 版脚本。

#### 导入 ROS Python 包

```python
import rospy
from std_msgs.msg import Int16
from std_msgs.msg import Float32MultiArray
```

`rospy` 是 ROS 的 Python 客户端库；`Int16` 用于接收整数命令；`Float32MultiArray` 用于发布浮点数组形式的控制指令。

#### 创建节点、订阅者与发布者

```python
rospy.init_node('yolo_det_trt', anonymous=True)
command_sub = rospy.Subscriber('/fcu_command/command', Int16, command_callback)
mission_pub = rospy.Publisher('/mission_follow', Float32MultiArray, queue_size=100)
```

#### 定义命令回调

```python
IsDetect = False

def command_callback(msg):
    global IsDetect
    if msg.data == 1001:
        print("开始前视识别追踪")
        IsDetect = True
    elif msg.data == 1002:
        print("开始俯视识别追踪")
        # 根据需要在此设置为俯视模式
    elif msg.data == 1003:
        print("停止识别追踪")
        IsDetect = False
```

#### 创建控制指令发布函数

`set_pose` 将控制数据组织为浮点数组，按 `fcu_core_v2` 的接口格式发布：

```python
def set_pose(x, y, z, yaw):
    msg = Float32MultiArray()
    msg.data = [
        yaw, 0,
        x, y, z,
        0, 0, 0, 0, 0, 0, 0]
    mission_pub.publish(msg)
```

#### 在主循环中控制识别状态

根据 `IsDetect` 判断是否执行识别跟踪。材料中的片段如下，返回方式以提供的替换脚本为准：

```python
global IsDetect
if not IsDetect:
    rospy.sleep(0.1)
    return frame, 0  # 跳出本次循环；在某些文件中（例如 yolo）改为 return，请参见替换文件
```
