# 环境部署

本节介绍单目相机（外置版）的接口、图传模块对频、画面显示和视频流读取方法。

![单目相机外置版图传模块接口位置](/产品使用手册/使用手册/视觉套件/单目外置/guide-image1.png)

- CN1 为网络接口；
- CN2 为串行接口；
- CN3 为电源接口及配对按键接口；
- CN5 为状态指示接口。

详细的接口定义如下图所示。

![单目相机外置版图传模块接口定义](/产品使用手册/使用手册/视觉套件/单目外置/guide-image2.png)

## 二、对频

图传模块上的拨动开关是模式选择开关，可根据需要选择 AP 模式或 STA 模式；轻触开关是配对按键。

![图传模块的模式选择开关、配对按键和连接线](/产品使用手册/使用手册/视觉套件/单目外置/guide-image3.png)

模块上的 6 个 LED 用于显示连接状态和信号强度。

![图传模块的状态指示灯和模式开关](/产品使用手册/使用手册/视觉套件/单目外置/guide-image4.png)

`CON` 为连接状态及电源指示灯：

- 插上电源后，`CON` 保持常亮；未配对时会短暂亮起后熄灭；
- `CON` 绿灯常亮表示模块已经连接；
- `CON` 绿灯闪烁表示模块配对成功；
- `CON` 绿灯不亮表示模块已经断开连接。

`RSS_1`～`RSS_3` 表示无线信号强度：

- `RSS_1`～`RSS_3` 全亮：接收信号强度大于 -48 dBm；
- `RSS_1`～`RSS_2` 亮：接收信号强度大于 -60 dBm、小于 -48 dBm；
- 只有 `RSS_1` 亮：接收信号强度大于 -72 dBm、小于 -60 dBm；
- `RSS_1`～`RSS_3` 均不亮，但 `CON` 绿灯保持常亮：接收信号强度小于 -72 dBm。

按照以下步骤完成对频：

1. 将地面端的拨动开关设为 AP 模式，将天空端的拨动开关设为 STA 模式；
2. 同时长按两个模块的轻触按键。

对频成功后，模块状态如下图所示。

![图传模块对频成功后的指示灯状态](/产品使用手册/使用手册/视觉套件/单目外置/guide-image5.png)

## 三、使用软件显示画面

### 1. 配置电脑的静态 IP

打开 Windows 设置，进入“网络和 Internet”，点击以太网的“属性”。

![在 Windows 网络设置中打开以太网属性](/产品使用手册/使用手册/视觉套件/单目外置/guide-image13.png)

找到“IP 分配”，点击“编辑”。

![编辑以太网的 IP 分配方式](/产品使用手册/使用手册/视觉套件/单目外置/guide-image14.png)

将 IP 设置改为“手动”，打开 IPv4，然后按下图填写并保存：

- IP 地址：`192.168.1.100`
- 子网掩码：`255.255.255.0`
- 网关：`192.168.1.1`
- 首选 DNS：`8.8.8.8`

![Windows 以太网静态 IP 参数](/产品使用手册/使用手册/视觉套件/单目外置/guide-image15.png)

### 2. 连接图传模块

使用网线连接图传地面端与电脑，同时确认天空端图传模块已经正常供电并连接成功。

![图传地面端通过网线连接电脑](/产品使用手册/使用手册/视觉套件/单目外置/guide-image6.png)

![IPCBatchTool 搜索到相机并显示连接成功](/产品使用手册/使用手册/视觉套件/单目外置/guide-image7.png)

双击设备可以打开摄像头画面。如果画面方向反转，需要调整图像设置。

![IPCBatchTool 中方向反转的摄像头画面](/产品使用手册/使用手册/视觉套件/单目外置/guide-image8.png)

![在 IPCBatchTool 中打开其它参数](/产品使用手册/使用手册/视觉套件/单目外置/guide-image9.png)

勾选“图像”，打开“翻转”和“镜像”开关，然后点击“确认”。

![在图像参数中打开翻转和镜像](/产品使用手册/使用手册/视觉套件/单目外置/guide-image10.png)

返回主界面后点击“应用”。

![在 IPCBatchTool 中应用图像参数](/产品使用手册/使用手册/视觉套件/单目外置/guide-image11.png)

摄像头画面配置完成后，应显示为正常方向。

![调整后正常显示的摄像头画面](/产品使用手册/使用手册/视觉套件/单目外置/guide-image12.png)

### 4. 配置视频流分辨率

Wi-Fi 模块默认使用 `2880×1616` 分辨率，对普通网络的传输压力较大，可根据实际网络环境调整视频流分辨率。

在浏览器中打开相机地址，例如 [http://192.168.1.129](http://192.168.1.129)。实际 IP 地址可以通过 IPCBatchTool 查看。

输入账号和密码：

```text
账号：admin
密码：123456
```

进入视频设置页面，配置分辨率并保存。

![相机网页中的视频流分辨率设置](/产品使用手册/使用手册/视觉套件/单目外置/guide-image16.png)

## 四、使用代码显示画面

### 1. 使用 FFmpeg 测试视频流

执行以下命令：

```bash
ffplay -rtsp_transport tcp -fflags nobuffer -flags low_delay -framedrop -probesize 32 -analyzeduration 0 -i rtsp://192.168.1.129:554/stream1
```

命令中的 IP 地址应替换为 IPCBatchTool 查到的实际相机 IP。

### 2. 配置 Python 环境

下载 [TcpNoDelay_recvstream_PC.py](https://fancinnov.com/file/TcpNoDelay_recvstream_PC.py)，安装对应版本的依赖：

```bash
pip install opencv-contrib-python==4.6.0.66
pip install numpy==1.24.0
```

依赖关系如下：

```text
TcpNoDelay_recvstream_PC.py
├── numpy v1.24.0
└── opencv-contrib-python v4.6.0.66
    └── numpy v1.24.0
```

### 3. 视频显示代码

将以下代码放入 Python 文件中：

```python
import cv2
import numpy as np
import subprocess
from multiprocessing import Array

def video_display(ffmpeg_command, frame_array, W_img, H_img):
    process = subprocess.Popen(ffmpeg_command, stdout=subprocess.PIPE)

    while True:
        raw_frame = process.stdout.read(W_img * H_img * 3)  # RGB 3 channels
        if not raw_frame:
            break

        # 将帧复制到共享内存中
        frame = np.frombuffer(raw_frame, dtype=np.uint8).reshape(H_img, W_img, 3)
        np.copyto(np.frombuffer(frame_array.get_obj(), dtype=np.uint8).reshape(H_img, W_img, 3), frame)

        # 显示帧
        cv2.imshow('Real-Time Video', frame)

        if cv2.waitKey(1) & 0xFF == ord('q'):
            break

    cv2.destroyAllWindows()
    process.terminate()

if __name__ == '__main__':
    W_img = 1280
    H_img = 720

    # 创建共享内存（用于进程间通信）
    shared_frame = Array('B', W_img * H_img * 3)  # RGB 3 通道，大小为像素数 × 3

    # 使用 ffmpeg 读取流并输出为 RGB 格式
    ffmpeg_command = [
        'ffplay', '-rtsp_transport', 'tcp', '-fflags', 'nobuffer',
        '-flags', 'low_delay', '-framedrop', '-probesize', '32',
        '-analyzeduration', '0', '-i', 'rtsp://192.168.1.129:554/stream1'
    ]

    video_display(ffmpeg_command, shared_frame, W_img, H_img)
```

运行 Python 文件：

```bash
python TcpNoDelay_recvstream_PC.py
```
