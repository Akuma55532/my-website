# 识别跟踪

本节介绍单目相机（外置版）的目标识别、前视跟踪和下视跟踪方法。

## 一、下载功能包

[下载单目外置版目标识别追踪功能包](https://fancinnov.com/file/h100%E9%80%8F%E4%BC%A0%E7%9B%AE%E6%A0%87%E8%AF%86%E5%88%AB%E8%BF%BD%E8%B8%AA%E5%8A%9F%E8%83%BD%E5%8C%85.zip)

## 二、调整相机分辨率

目标检测和跟踪对实时性要求较高，因此需要调整相机的分辨率和帧率。

先按照 [环境部署](./环境部署.md) 完成相机连接。连接成功后，可以在 IPCBatchTool 中查看摄像头的 IP 地址。

![在 IPCBatchTool 中查看摄像头 IP 地址](/产品使用手册/使用手册/视觉套件/单目外置/image1.png)

在浏览器中输入该 IP 地址，进入摄像头设置页面。登录信息为：

```text
用户名：admin
密码：123456
```

![登录摄像头设置页面](/产品使用手册/使用手册/视觉套件/单目外置/image2.png)

进入“Configure → Stream Manager → Video Setting”，找到分辨率和帧率设置。

![摄像头网页中的视频设置入口](/产品使用手册/使用手册/视觉套件/单目外置/image3.png)

将分辨率改为 `1280×720`，帧率改为 `25`，然后点击“Save”。

![将分辨率设为 1280×720、帧率设为 25](/产品使用手册/使用手册/视觉套件/单目外置/image4.png)

## 三、安装本地 YOLO 环境

教程使用的环境为：

- 操作系统：Windows 11；
- Python：3.10.18；
- 推理方式：CPU。

安装依赖：

```bash
pip install opencv-python==4.12.0.88
pip install pyserial==3.5
pip install ultralytics==8.3.249
```

在脚本的 `ffmpeg_command` 中，将视频流地址改为当前相机的实际 IP 地址：

```python
ffmpeg_command = [
    "ffmpeg",
    "-rtsp_transport", "tcp",
    "-fflags", "nobuffer+flush_packets",
    "-flags", "low_delay",
    "-probesize", "32",
    "-analyzeduration", "0",
    "-i", "rtsp://192.168.1.33:554/stream1",
    "-pix_fmt", "bgr24",
    "-f", "rawvideo",
    "-vf", f"fps={TARGET_FPS}",
    "-"
]
```

每台相机的 IP 地址可能不同，示例中的 `192.168.1.33` 应替换为实际地址。

运行功能包中的识别脚本。出现目标框和识别结果，表示识别功能已经运行。

![YOLO 目标识别运行结果](/产品使用手册/使用手册/视觉套件/单目外置/image5.png)

## 四、添加跟踪功能

跟踪功能通过 1 公里透传模块向无人机下发飞行指令。`utils` 文件夹中的 `datalink_serial.py` 负责通过串口连接无人机。

将电脑拓展坞与图传地面端的串口接口连接。

![电脑拓展坞连接图传地面端串口](/产品使用手册/使用手册/视觉套件/单目外置/image6.png)

打开 Windows 设备管理器，找到对应的串口设备。下图示例中的端口为 `COM56`。

![在设备管理器中查看图传模块串口号](/产品使用手册/使用手册/视觉套件/单目外置/image7.png)

根据查到的 COM 端口，修改 `datalink_serial.py` 中的串口设备。

![在 datalink_serial.py 中修改串口号](/产品使用手册/使用手册/视觉套件/单目外置/image8.png)

飞机端的串口接线如下图所示。

**注意：透传口占用的串口与 Mlink 模块使用的是同一个串口。**

![图传天空端串口与飞控串口的位置](/产品使用手册/使用手册/视觉套件/单目外置/image9.png)

![图传天空端与飞控串口接线实物图](/产品使用手册/使用手册/视觉套件/单目外置/image10.png)

完成连接和端口修改后，运行 `main.py`：

```bash
python main.py
```

## 五、切换为下视跟踪

功能包默认使用前视跟踪。将 `main.py` 文件中的 `TrackDown` 改为 `True`，即可启用下视跟踪。
