## 更换虚拟机默认连接网卡

虚拟机默认连接无线网卡，这时候如果用户想要连接有线网卡(以太网)，就需要一点设置更改

VMware虚拟机左上角的`编辑` -> `虚拟网络编辑器` -> `更改设置`

![](../../static/通用教程/VMware虚拟机/更换网卡1.png)

将`VMnet0`桥接至你的有线网卡上。

![](../../static/通用教程/VMware虚拟机/更换网卡2.png)

最后使用`ping`指令测试一下网络连通性
